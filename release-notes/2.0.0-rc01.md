# svelte-pure-admin 2.0.0-rc01 — Release Notes

**Released:** 2026-10-22 · **Pre-release** (`npm install @keenmate/svelte-pure-admin@rc`)

This is the first **2.0** pre-release, and this guide covers everything since the last stable
release, **1.8.0**. The 1.9.0 line that followed it (rc01–rc03 published as pre-releases,
rc04–rc06 never published) continues here as 2.0.0. It became a major version because it renames
props across the library with no aliases and requires `@keenmate/pure-admin-core` 3.x. Under a
1.x number, a `^1.8.0` range would have pulled it in.

The release moves the library from `@keenmate/pure-admin-core` **2.7.2 to 3.3.0-rc09** (and
`@keenmate/pure-css` to 2.0), reshapes the Navbar, and renames props so svelte-pure-admin and
keen-pure-admin (Phoenix, also 2.0) share **one prop vocabulary**.

Most breaking changes are renames with a 1:1 replacement, and there are **no aliases**. Svelte
ignores unknown props instead of failing, so an old name silently does nothing. Search your code
for each old name in the tables below.

The full per-change list (the 2.0.0-rc01 section plus the 1.9.0-rc01–rc05 sections) is in
[`CHANGELOG.md`](https://github.com/KeenMate/svelte-pure-admin/blob/v2.0.0-rc01/CHANGELOG.md).
For core's side of the same changes (CSS tokens, utilities, Sass), see
[pure-admin-core 3.3.0-rc08 release notes](https://github.com/KeenMate/pure-admin/blob/v3.3.0-rc08/packages/core/release-notes/3.3.0-rc08.md).

| Package | Version |
|---|---|

## Upgrade checklist

- [ ] Bump `@keenmate/pure-admin-core` to `^3.3.0-rc09` and `@keenmate/pure-css` to `^2.0.0-rc04`;
      reinstall themes built against core 3.3.0-rc09.
- [ ] Rename booleans to `is*` / `has*` / `should*`, including native ones (`disabled` →
      `isDisabled`, `bind:checked` → `bind:isChecked`, …) — [tables](#booleans-are-is--has--should).
- [ ] Overlays bind `isOpen` instead of `show` — [table](#overlay-open-state-is-isopen).
- [ ] Rich content goes in the snippet with the bare name; plain text goes in `*Text` —
      [table](#text-vs-rich-snippets).
- [ ] Layout props use CSS names (`align` → `justify`, `position` → `placement`, …) —
      [table](#layout-and-placement-props-use-css-names).
- [ ] `variant` is always the role colour; options that exclude each other are one enum —
      [table](#one-enum-per-choice-variant-is-the-role-colour).
- [ ] CSS in your own markup: `ml-/mr-/pl-/pr-*` → `ms-/me-/ps-/pe-*`, muted text →
      `.text-muted`, `--pc-<role>` → `--pc-<role>-color` — [foundation](#breaking--foundation-core-3x--pure-css-20).
- [ ] Mark required controls with `isRequired` on the control, not on `FormLabel` / `FormField` /
      `FormGroup`.
- [ ] Rebuild your navbar on the three-zone `Navbar` (`start` / `center` / `end`) with `AppHeader`
      / `NavMenu` / `PageHeader` — [other breaking changes](#breaking--other-changes).
- [ ] Replace `MetricList` / `StatusList` / `ActivityFeed` / `QuickActions` (removed).

## The naming rules

The names follow the shared keen / svelte rules in core's
[`fidelity/NAMING.md`](https://github.com/KeenMate/pure-admin/blob/v3.3.0-rc09/packages/core/fidelity/NAMING.md),
and a check (`npm run fidelity:naming` in pure-admin) keeps the two wrappers in step.

| Rule | Examples |
|---|---|
| Every boolean is `is*` / `has*` / `should*`, native attributes included | `isDisabled`, `isRequired`, `hasClose`, `shouldWrapHeader` |
| `has*` shows a part; a part that is on by default is turned off with `false` | `hasBorder={false}`, `hasHeader={false}` |
| Overlays bind `isOpen`; conditionally rendered elements use `isVisible` | `<Modal bind:isOpen>`, `<Toast isVisible>` |
| The bare name is the rich snippet; plain text is `*Text` | `title` snippet / `titleText`, `label` / `labelText` |
| An icon by name is `iconName` (rendered through `<Icon>`), next to an `icon` snippet | `<Button iconName="fas fa-save">` |
| `variant` is the role colour; `themeColor` is the 1–9 palette slot | `<Loader variant="success">`, `<Fields themeColor={3}>` |
| `type` = which predefined design, `mode` = which behaviour, `layout` = arrangement, `density` = spacing | `<Tabs type="pills">`, `<Fields layout="table" density="compact">` |
| Layout props are named after the CSS property they drive | `justify`, `align`, `textAlign` |
| `placement` = where a floating element sits; `<part>Placement` = where a part sits | `<Tooltip placement="top">`, `labelPlacement`, `iconPlacement` |
| `style` is only ever the inline CSS string | |

## Breaking — prop renames

### Booleans are `is*` / `has*` / `should*`

**Native boolean attributes.** The component still writes the native attribute.

| Old | New | Components |
|---|---|---|
| `disabled` | `isDisabled` | Button, SplitButton, SplitButtonItem, Checkbox, CheckboxBox, CheckboxListItem, Radio, Input, NumberInput, DateInput, ColorInput, FileInput, RangeInput, Select, Textarea, FilterCard, TabItem, `dialogService` buttons |
| `readonly` | `isReadonly` | form controls |
| `required` | `isRequired` | form controls (core draws the asterisk from it) |
| `multiple` | `isMultiple` | Select, FileInput |
| `checked` / `bind:checked` | `isChecked` / `bind:isChecked` | Checkbox, Radio |

**State flags → `is*`**

| Old | New | Component |
|---|---|---|
| `active` | `isActive` | TabItem, TabPanel, CardTab, CardTabContent, SidebarItem |
| `vertical` / `nowrap` | `isVertical` / `isNowrap` | ButtonGroup |
| `noPadding` / `grow` / `shrink` | `isNoPadding` / `isGrow` / `isShrink` | Column |
| `noGutter` / `sameHeight` | `isNoGutter` / `isSameHeight` | Grid |
| `showAll` | `isShowAll` | BadgeGroup |
| `level2` | `isLevel2` | NavDropdown |
| `wrapLabels` | `isWrapLabels` | Tabs |
| `shouldKeepLayout` | `isKeepLayout` | Timeline |
| `touched` | `isTouched` | Input, NumberInput, DateInput, Select, Textarea, FormField (also the `children` snippet context) |
| `multiline` | `isMultiline` | Tooltip |
| `titleTooltipMultiline` / `descriptionTooltipMultiline` | `titleTooltipIsMultiline` / `descriptionTooltipIsMultiline` | Card |
| `horizontal` | `isHorizontal` | FormField, FormGroup |
| `burgerActive` | `isBurgerActive` | Navbar |
| `removable` | `isRemovable` | ProfilePanelFavoriteItem |
| `endVertical` | `isEndVertical` | Footer |
| `disablePrevious` / `disableNext` | `isPreviousDisabled` / `isNextDisabled` | Pager |
| `auto` / `managed` | `isAuto` / `isManaged` | FitContainer / FitSlot |
| `full` | `isFull` | Field, DescTableItem |
| `noDelta` | `isNoDelta` | KpiSparklineList |

**Showing a part → `has*`**

| Old | New | Component |
|---|---|---|
| `shouldShowClose` | `hasClose` | Modal |
| `shouldShowBackdrop` | `hasBackdrop` | DetailView |
| `shouldShowCheckboxes` | `hasCheckboxes` | NotificationsPanel |
| `shouldShowProgress` | `hasProgress` | Toast, `toastService` options |
| `showInfo` / `showPageInput` | `hasInfo` / `hasPageInput` | Pager |
| `showValue` | `hasValue` | ColorInput, RangeInput |
| `showCopy` | `hasCopy` | CodeBlockWithHeader |
| `showBurger` | `hasBurger` | Navbar |
| `shouldShowToggle` / `…Clear` / `…Refresh` / `…AdvancedActions` | `hasToggle` / `hasClear` / `hasRefresh` / `hasAdvancedActions` | FilterCard |
| `noHeader` / `noPreviousValue` / `noDeltaPercent` / `noTargetBar` | `hasHeader` / `hasPreviousValue` / `hasDeltaPercent` / `hasTargetBar` (default `true`; pass `={false}`) | KpiStrip |

**Behaviour → `should*`**

| Old | New | Component |
|---|---|---|
| `headerWrap` | `shouldWrapHeader` | Card |
| `allowHtml` | `shouldRenderHtml` | NavbarSearchField, SearchResults |
| `disableShortcuts` | `shouldHandleShortcuts` (default `true`, inverted) | PureAdminProvider |

### Overlay open state is `isOpen`

`show` → `isOpen` (bindable) on **Modal, SlidePanel, DetailView, Popconfirm, CommandPalette,
ProfilePanel, NotificationBell, NotificationsPanel, ShortcutHelpDialog, TabsOverflow**.
For elements that are rendered or not rather than opened: `Toast` `show` → `isVisible`,
`FormErrorSummary` `show` → `isVisible`.

### Text vs rich snippets

| Old | New | Component |
|---|---|---|
| `labelSnippet` | `label` (snippet) | Checkbox, Radio, Field |
| `titleSnippet` | `title` (snippet) | FieldGroup |
| `valueSnippet` | removed — `children` is the rich value | Field |
| `iconTemplate` | `icon` (snippet) | TimelineItem |
| `unit` / `prefix` | `unitText` / `prefixText` | KpiBentoTile, KpiEditorialTile, KpiGauge, KpiHeroMain, KpiHeroSide, KpiSparklineRow, KpiStripRow |
| `valueUnit` / `valuePrefix` | `unitText` / `prefixText` | KpiTerminalTile |
| `text` | removed — the label is `children` | LoadMore |
| `count` | `countText` | LoadMore |
| `label` (row) | `labelText` | RangeGroup rows |
| `headerActions` (snippet) | `actions` | TableCard, TableContainer (`Card` keeps `headerActions` / `footerActions`) |

**Icons by name.** `iconName` is a string rendered through `<Icon>`, so your configured icon
provider resolves it. The `icon` snippet wins when both are set. New `iconName` on: Button,
SplitButton, SplitButtonItem, Badge, CompositeBadge, Stat, Alert, Callout, Toast, SidebarItem,
SidebarSearch, TabItem, TimelineItem, ProfileButton, ProfilePanelFavoriteItem,
ProfilePanelNavItem. Card gains `titleIconName`.

| Old | New | Component |
|---|---|---|
| `titleIcon` | `titleIconName` | Modal |
| `navIcon` | `iconText` | NavItem (plain text, inserted as escaped text) |
| `collapseIcon` / `moreLabel` / `collapseLabel` | `collapseIconText` / `moreLabelText` / `collapseLabelText` | NavMenu |
| `icon` | `iconVariant` (it picks the glyph's colour) | Popconfirm |

### Removed aliases and dead props

- FormGroup `horizontal` (use `isHorizontal`) and `isError` / `isSuccess` (use `validation`).
- ButtonGroup `mdVertical` / `lgHorizontal` → `verticalAt="md"` / `horizontalAt="lg"`.
- TabItem `width` / `height` → pass `minwr-N` / `minhr-N` via `class`.
- Table `isHover` / `isBorderless` (they never emitted anything; hover is built in).
- `required` / `isRequired` on FormLabel / FormField / FormGroup. Put `isRequired` on the control.
- The `TextMode` type; LoadMore's unused `shouldShowCount`.

## Breaking — foundation (core 3.x / pure-css 2.0)

These matter wherever **your own** markup or CSS uses framework classes and tokens. The
components already emit the new names.

- **CSS variable prefix (`--pa-*` → `--pc-*`):** runtime foundation variables and the grid /
  mode classes moved to `--pc-*` / `.pc-*` (`.pa-row` / `.pa-col-*` → `.pc-row` / `.pc-col-*`,
  `.pa-mode-*` → `.pc-mode-*`, `h-Nx` → `hr-N`); component tokens stay `--pa-*`. Rename these in
  your own markup and inline `style="--…"` overrides.
- **Role colours end in `-color`:** `--pc-primary` → `--pc-primary-color`, likewise
  `--pc-<role>` → `--pc-<role>-color`, and `accent` became `primary`.
- **Muted text is `.text-muted`.** `.text-secondary` is now the secondary role colour.
  `<Text variant="secondary">` keeps the role colour; `<Paragraph isMuted>` emits `.text-muted`.
- **Utilities are logical-only:** `ml-/mr-/pl-/pr-*` → `ms-/me-/ps-/pe-*`, `border-left/right` →
  `border-start/end`, `rounded-left/right` → `rounded-start/end`.
- **Typography:** the `.pa-text` component is gone. `Paragraph`, `Text` and `Heading` emit the
  flat `text-*` utilities.
- **Buttons and tabs:** the classes became `pa-btn--justify-*` and `pa-tabs--justify-*`, emitted
  by the `justify` prop.
- **Button groups are 8px apart** (core 3.3.0-rc09), the same as card actions and footers. Use
  `<ButtonGroup isCompact>` for the old tight 3px cluster (table row actions).

## Breaking — other changes

- **`Navbar` is a universal three-zone layout** (`start` / `center` / `end`), with
  `AppHeader` / `NavMenu` / `PageHeader` as composable pieces. It replaces the old fixed snippets
  (`brand`, `navStart`, `search`, `title`, …). The burger is a fixed anchor before the zones. The
  `pa-header__*` block is now `pa-navbar__*` / `pa-app-header` / `pa-page-header` / `pa-navmenu`
  (no aliases). The `isTitleFit` / `titleFitPriority` / `fitPriority` props are gone; use
  `FitSlot` / `FitStep`.
- **Removed components:** `MetricList`, `StatusList`, `ActivityFeed` and `QuickActions` (with
  their item components) emitted classes core never had. Use `Fields` / `Table`, `Badge`,
  `List` / `Timeline` and `ButtonGroup`.
- **Required is attribute-driven:** core draws the asterisk from the control's `required`
  attribute, so `FormLabel` / `FormField` / `FormGroup` lost their `required` props.
- **Classes that don't exist in core are gone.** Every emitted class was checked against core's
  compiled CSS, and invented ones were removed (Table `--hover` / `--borderless`, FormHelp
  `info`, CodeBlock `typescript` / `svelte`, …). `KpiEditorial` `is2Columns` became the
  `gridLayout` enum.
- **`Button` renders its label bare.** It no longer wraps the label in `.pa-btn__label`, except
  for `justify="center"` or truncation. The icon-only glyph also renders bare.
- **`Sidebar`:** the fake `mode="sticky"` is gone (sticky is the body class
  `pc-layout--sticky`). Use the new `isIconCollapse` for the icon rail.
- **`Textarea`** no longer emits its own validation-colour classes (core doesn't define them);
  show errors through the form group.
- **`ToastContainer`** picks the icon from the toast's `variant`; `toastService`'s `iconClass`
  is now only an override.
- **`Spinner`** renders a `<span>` (valid inside text).

## New components and features

**Navbar, search and layout (since 1.8.0)**
- **Navbar fit:** `FitSlot` / `FitStep` let any header slot hide, step down or move to the
  sidebar, lowest priority first, when the row runs out of room. `NavMenu` collapses its items
  (`collapse="menu" | "sidebar"`).
- **Search suite:** `SearchResults`, the live `NavbarSearchField`, the type-and-go
  `NavbarSearchInput` and `SidebarSearch`, and `CommandPalette` size presets.
- **Sidebar:** `SidebarSection`, `SidebarDivider`, a working drag-to-resize, and active state on
  `NavItem`.
- **New components:** `Splitter` / `SplitterPane` / `SplitterGutter`, `RangeGroup` (multi-range
  filter with URL sync), `Stat isFit` (fit-to-box tiles).

**Components**
- **`Icon`** with a pluggable provider: `masked()` (default), `fontAwesome()`, `svgIcons()`,
  `combine()`. Configure it once with `PureAdminProvider iconProvider`. Hover behaviour comes from
  the provider; `isInteractive` makes a standalone icon react on hover.
- **`ContainerBreakpoint`:** mounts only the branch for the current container-width mode.
  **`FitContainer`:** folds a toolbar row to fit its width.
- **`NotificationBell`** (bell, badge, panel anchor), **`SectionTitle`**, **`FormActions`**.

**Cards**
- Title and description tooltips (`titleTooltip` / `descriptionTooltip`) that show only while
  the text is truncated (`*TooltipMode="always"` shows them on every hover).
- `headerActionsCollapsed`, a compact fallback for header actions.
- `footer` and `footerActions` render together (leading content on the left, actions on the
  right).
- `href` / `tag` / `target` render the whole card as a link; `bodyClass` adds classes to the body.

**Buttons**
- `isRipple` now actually ripples: one 0.45s grow-and-fade from the click point.
- `rippleType`: `center`, `pulse`, `double-pulse`, or any type you define in your own CSS (it
  is timed from your animation; nothing to register).
- `ButtonGroup isCompact`, `verticalAt` / `horizontalAt`.
- SplitButton items take a role `variant`; `shouldKeepOpen`; `titleText` / `ariaLabel` /
  `toggleAriaLabel`.

**Other components**
- **Alert / Callout:** a rich `heading` snippet.
- **ListItem:** a `meta` snippet and `isHighlighted`.
- **Loader:** `type` `grid` / `ripple` / `dual-ring`.
- **Pager:** `first` / `previous` / `next` / `last` snippets, translated labels, and
  `infoPlacement="start"`.
- **Modal:** `titleIconName`, `shouldCloseOnBackdrop`.
- **`dialogService`:** `isBanded`; an `icon` derived from the `variant`; `closeOnBackdrop` now
  actually works.
- **RangeGroup:** `resetText` / `applyText` / `hasActions`.
- **KpiTerminal:** `liveText` and a `headerControls` snippet.
- **TabItem:** `isDisabled` and `titleText`.
- **Table:** `isPlain`.
- **Smaller additions:** CodeBlock `isNumbered`, CheckboxListItem `isSelected`, Timeline
  `isSingleColumn`, CompositeBadge `iconVariant`, Field `valueVariant="info"`,
  RadioGroup / CheckboxGroup `layout`.

**Shell**
- `SettingsPanel` builds its theme mode and colour-variant controls from each theme's manifest,
  and adds an overlay (floating drawer) sidebar behaviour.
- Mode and variant changes dispatch `pa:theme-change` events.
- The collapsed sidebar's submenu flyouts stay inside the viewport.
- **Command palette:**
  - `g <letter>` shortcuts
  - a keyboard-navigable home screen
  - `PgUp` / `PgDn` / `Home` / `End`
  - icons rendered through `<Icon>`
  - global search finds commands
  - `Esc` / `Backspace` step back a level

## Fixes

- **CodeBlockWithHeader:** with several blocks on a page, every copy button copied the first
  block.
- **Heatmap:** a custom column count ignored `isCompact`.
- **Loader:** `variant="primary"` rendered without colour.
- **`DataVizVariant`** now accepts `'primary'`.
- **Radio:** a disabled radio now also gets `.pa-radio--disabled` on its label.
- **Tooltips inside cards:** Floating-UI now positions them, so the card no longer clips them.
- **Detail panel:** the close button's `aria-label` now matches core and keen.
- **Navbar burger:** its icon now follows the sidebar's real open state.
