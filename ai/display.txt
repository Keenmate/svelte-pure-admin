DISPLAY COMPONENTS
==================

CRITICAL: This is a Svelte 5 component library (@keenmate/svelte-pure-admin)
- All components use Svelte 5 runes ($props, $state, $derived)
- Content slots use Snippets ({#snippet}), NOT legacy <slot>
- All CSS classes use BEM naming: pa-[block]__[element]--[modifier]
- Import components from '@keenmate/svelte-pure-admin'

INSTALLATION
------------
npm install @keenmate/svelte-pure-admin

CSS must be imported separately:
<script>
  import '@keenmate/pure-admin-core/css';
</script>


BUTTON
------
Props:
  variant?       'primary' | 'secondary' | 'success' | 'danger' | 'warning'
                 | 'info' | 'light' | 'dark' | 'ghost'
  themeColor?    1-9 - Theme color slot (pa-btn--color-N, overrides variant)
  size?          'xs' | 'sm' | 'lg' | 'xl'
  isOutline?     boolean (false)
  isBlock?       boolean (false) - Full width
  isIconOnly?    boolean (false) - Square icon-only button (glyph renders bare)
  isLoading?     boolean (false)
  isDisabled?    boolean (false) - Emits native disabled
  isRipple?      boolean (false) - Ripple on click, grows from the click point (0.45s).
                 The component plays it itself - no script needed.
  rippleType?    'center' | 'pulse' | 'double-pulse' | any custom name (with isRipple)
                 -> pa-btn--ripple-{rippleType}. Custom: define .pa-btn--ripple-<name> with an
                 animation on .pa-btn--ripple-active in your own CSS; the button times it
                 from the animation automatically.
  justify?       'start' | 'end' | 'center' | 'between' -> pa-btn--justify-*
  iconPlacement? 'start' (default) | 'end'
  shouldTruncateText? boolean (false) - Ellipsis label (pair with a width utility, e.g. maxwr-10)
  isInputGroupButton? boolean (false) - Adds pa-input-group__button
  type?          'button' (default) | 'submit' | 'reset'
  href?          string - Renders <a>
  target?        '_blank' | '_self' | '_parent' | '_top' (with href)
  titleText?     string - title attribute
  iconName?      string - Icon name rendered through <Icon> (the icon snippet wins)
  onclick?       (event: MouseEvent) => void
  class?         string
  ...rest        data-*, aria-* forwarded

Snippets:
  icon?          Rich icon (pa-btn__icon)
  children?      Label (rendered bare - no .pa-btn__label wrapper unless justify="center"/truncation)

<Button variant="primary" iconName="fas fa-save" isRipple>Save</Button>
<Button variant="primary" isRipple rippleType="pulse">Pulse</Button>
<Button variant="secondary" isOutline justify="between" isBlock>Options</Button>


BUTTONGROUP
-----------
Default gap is 8px (same as card actions and footers).

Props:
  isCompact?     boolean (false) - Tight 3px gap (pa-btn-group--compact); use for table
                 row-action icon clusters
  isVertical?    boolean (false)
  align?         'center' | 'end' | 'stretch' (vertical groups only)
  verticalAt?    'sm' | 'md' | 'lg' | 'xl' - Vertical from this breakpoint up
  horizontalAt?  'sm' | 'md' | 'lg' | 'xl' - Horizontal from this breakpoint up
  responsive?    'md-vertical' | 'lg-horizontal' | ... - Combined token shorthand
  isNowrap?      boolean (false) - Single line, may overflow
  class?         string
  children?      Snippet

<ButtonGroup isCompact>
  <Button size="xs" isIconOnly iconName="edit" titleText="Edit" />
  <Button size="xs" isIconOnly iconName="trash" variant="danger" titleText="Delete" />
</ButtonGroup>


SPLITBUTTON / SPLITBUTTONITEM
-----------------------------
SplitButton Props: variant?, themeColor?, size?, isOutline?, isDisabled?,
  isOpen? (bindable), placement? 'bottom-end' | 'top-end', onclick?, titleText?,
  ariaLabel? (main button), toggleAriaLabel? (chevron), iconName?, class?
  Snippets: icon?, children?, toggleIcon?, menu? (SplitButtonItem list)
SplitButtonItem Props: variant? (role colour -> pa-btn-split__item--{variant}),
  shouldKeepOpen? (data-pa-keep-open), isDisabled?, onclick?, iconName?, class?
  Snippets: icon?, action?, children?

<SplitButton variant="primary" onclick={save}>
  Save
  {#snippet menu()}
    <SplitButtonItem onclick={saveAs}>Save as...</SplitButtonItem>
    <SplitButtonItem variant="danger" onclick={discard}>Discard</SplitButtonItem>
  {/snippet}
</SplitButton>


ICON
----
Renders an icon by name through the configured providers. Framework affordance names
(masked pa-icon--NAME) resolve built-in; configure the rest once:

<PureAdminProvider iconProviders={[svgIcons(myLucideSet), fontAwesome()]}>
Providers: fontAwesome({ style?, fixedWidth? }), svgIcons(map, options?), masked(), combine(...)

Props:
  name           string (required)
  size?          string - CSS length, e.g. '1.25rem' (default inherits 1em)
  isInteractive? boolean (false) - Standalone icon reacts on hover (.pc-icon-hover)
  label?         string - Accessible name (role="img"); otherwise aria-hidden
  class?         string

<Icon name="search" />
Components with an iconName prop render it through <Icon>.


CARD
----
The main container component. Supports title, header/footer snippets, ghost mode,
stat card style, live state indicators, and inline tabs.

Props:
  variant?       'primary' | 'success' | 'warning' | 'danger'
                 | 'color-1' through 'color-9'
  titleText?     string - Simple title text in header
  title?         Snippet - Rich content title (alternative to titleText)
  titleIconName? string - Icon name rendered through <Icon> before the title
  descriptionText? string - Inline description with title, truncates with ellipsis
  description?   Snippet - Rich description (alternative to descriptionText)
  subtitleText?  string - Below title (deprecated, use descriptionText)
  titleTooltip?  boolean | string - Tooltip on the title (true = the title's own text)
  descriptionTooltip? boolean | string - Tooltip on the description
  titleTooltipMode? / descriptionTooltipMode?  'overflow' (default: only while truncated) | 'always'
  titleTooltipPlacement? / descriptionTooltipPlacement?  'top' (default) | 'bottom' | 'start' | 'end'
  titleTooltipVariant?, titleTooltipIsMultiline?, titleTooltipIsHelp?, titleTooltipIsKeyword?
                 (same set for description*) - Tooltip styling
  shouldWrapHeader? boolean (false) - Allow description to wrap to its own line
  isHeaderUnderlined? boolean (false) - Accent border under the header
  headerUnderlineColor? 'success' | 'warning' | 'danger' | 'info'
  headerUnderlineThemeColor? 1-9
  hasInlineTabs? boolean (false) - Pill-style tab buttons in header
  isActionsOverflow? boolean (false) - Collapse header actions into a "..." menu when tight (JS)
  actionsOverflowFrom? 'start' | 'end' (default 'end') - Which end drops first
  headerClass?   string - Additional CSS classes on the header element
  bodyClass?     string - Additional CSS classes on the pa-card__body element
  isGhost?       boolean (false) - Invisible container (no bg, border, shadow)
  isStat?        boolean (false) - Stat card styling
  hasPadding?    boolean (true) - Body has padding (false removes it)
  liveState?     'up' | 'down' | 'neutral' - Tinted background for live data
  href?          string - Render the whole card as a link (<a class="pa-card">)
  tag?           'div' | 'a' (default: 'a' with href, else 'div')
  target?        string - Link target (with href)
  style?         string - Inline style on the card root
  class?         string - Additional CSS classes

Snippets:
  header?        Custom header content (replaces default title layout)
  titleIcon?     Icon before title text (rich; wins over titleIconName)
  headerActions? Header action buttons (.pa-card__actions in the header)
  headerActionsCollapsed? Compact fallback for headerActions (e.g. a SplitButton);
                 emits .pa-card__actions--responsive (CSS container query swaps them)
  tabs?          Tab buttons in header (replaces other header content)
  children?      Body content (main card content)
  footer?        Footer leading content (left)
  footerActions? Footer action buttons (.pa-card__actions, right)
                 footer and footerActions render TOGETHER in one footer row

Basic card:

<Card titleText="Users">
  <p>Card body content goes here.</p>
</Card>

Card with header actions and footer:

<Card titleText="Active Users" descriptionText="Last 30 days" descriptionTooltip>
  {#snippet headerActions()}
    <Button variant="secondary" size="sm">Export</Button>
    <Button variant="primary" size="sm">Add User</Button>
  {/snippet}

  <Table isStriped>
    <thead><tr><th>Name</th><th>Email</th></tr></thead>
    <tbody>
      <tr><td>John</td><td>john@example.com</td></tr>
    </tbody>
  </Table>

  {#snippet footer()}
    <Button variant="secondary">Back</Button>
  {/snippet}
  {#snippet footerActions()}
    <Button variant="secondary">Cancel</Button>
    <Button variant="primary">Save</Button>
  {/snippet}
</Card>

Card with custom header snippet:

<Card>
  {#snippet header()}
    <h3>Custom Header</h3>
    <Badge variant="success">Live</Badge>
  {/snippet}
  Body content here.
</Card>

Ghost card (invisible container, same spacing):

<Card isGhost titleText="Ghost Section">
  <p>No background, border, or shadow.</p>
</Card>

Live state card (tinted background reflecting data changes):

<Card titleText="Stock Price" liveState="up">
  <p>$142.50 (+2.3%)</p>
</Card>

Card with tabs:

<script>
  let activeTab = $state('overview');
</script>

<Card hasInlineTabs>
  {#snippet tabs()}
    <CardTab isActive={activeTab === 'overview'} onclick={() => activeTab = 'overview'}>
      Overview
    </CardTab>
    <CardTab isActive={activeTab === 'details'} onclick={() => activeTab = 'details'}>
      Details
    </CardTab>
  {/snippet}

  {#if activeTab === 'overview'}
    <p>Overview content</p>
  {:else}
    <p>Details content</p>
  {/if}
</Card>

Stat card (inside a Grid):

<Grid>
  <Column md="1-4">
    <Card isStat titleText="Total Revenue">
      <Stat number="$48,200" labelText="Revenue" changeText="+12.5%" changeDirection="positive" layout="hero" />
    </Card>
  </Column>
</Grid>

FILTERCARD
----------
Expandable filter card with inline filters and collapsible advanced section.
Built on top of pa-card with pa-filter-card classes.

Props:
  isExpanded?            boolean (false, bindable) - Advanced filters expanded
  hasToggle?             boolean (true) - Show expand/collapse button
  hasClear?              boolean (true) - Show clear all button
  hasRefresh?            boolean (true) - Show refresh button
  hasAdvancedActions?    boolean (true) - Show Apply/Clear in advanced section
  isDisabled?            boolean (false) - Disable all inputs
  isLoading?             boolean (false) - Loading state
  class?                 string
  onclear?               () => void
  onrefresh?             () => void
  onapply?               () => void
  ontoggle?              (expanded: boolean) => void

Snippets:
  filters?               Main inline filters (search, selects)
  advancedFilters?       Collapsible advanced filters section
  actions?               Custom action buttons

<FilterCard
  onclear={handleClear}
  onrefresh={handleRefresh}
  onapply={handleApply}
>
  {#snippet filters()}
    <Input placeholder="Search..." bind:value={search} />
    <Select bind:value={status}>
      <option value="">All</option>
      <option value="active">Active</option>
    </Select>
  {/snippet}

  {#snippet advancedFilters()}
    <FormGroup>
      <FormLabel>Date Range</FormLabel>
      <Input type="date" bind:value={startDate} />
    </FormGroup>
  {/snippet}
</FilterCard>


TABLECARD
---------
A card container specifically for tables. No body padding, handles table overflow
and border-radius properly.

Props:
  titleText?     string - Card title
  descriptionText? string - Inline description next to the title
  variant?       'primary' | 'success' | 'warning' | 'danger'
  themeColor?    1-9 (theme color)
  isScrollable?  boolean (false) - Horizontal scrolling for wide tables
  isPlain?       boolean (false) - Remove card styling (border, shadow, bg)
  class?         string

Snippets:
  header?        Custom header (replaces title)
  actions?       Header action buttons
  children?      Table content
  footer?        Footer (pagination, summary)

<TableCard titleText="Users">
  {#snippet actions()}
    <Button variant="primary" size="sm">Add User</Button>
  {/snippet}

  <Table isStriped>
    <thead>
      <tr><th>Name</th><th>Email</th><th>Status</th></tr>
    </thead>

TABLE
-----
HTML table with visual modifiers. Row hover is built in (no prop).
For row-action icon clusters use <ButtonGroup isCompact> (3px gap; the default group gap is 8px).

Props:
  isStriped?       boolean (false) - Zebra striping
  isCompact?       boolean (false) - Reduced padding (alias for size="xs")
  size?            'xs' | 'sm' | 'lg' | 'xl' - Cell padding size
  isBordered?      boolean (false) - Full borders on all sides
  isPlain?         boolean (false) - Neutral ruled table (no header fill / row backgrounds);
                   pair with isBordered for print-style grids
  isResponsive?    boolean (false) - Horizontal scroll on overflow
  isResponsiveGrid? boolean (false) - Grid layout, collapses to cards on mobile
  class?           string
  children?        Snippet

<Table isStriped>
  <thead>
    <tr>
      <th>ID</th>
      <th>Name</th>
      <th>Role</th>
      <th>Status</th>
    </tr>
  </thead>
  <tbody>
    {#each users as user}
      <tr>
        <td>{user.id}</td>
        <td>{user.name}</td>
        <td>{user.role}</td>
        <td><Badge variant={user.active ? 'success' : 'danger'}>{user.active ? 'Active' : 'Inactive'}</Badge></td>
      </tr>
    {/each}
  </tbody>
</Table>

Compact bordered table:

<Table isCompact isBordered>
  <thead><tr><th>Key</th><th>Value</th></tr></thead>
  <tbody>
    <tr><td>Version</td><td>1.5.0</td></tr>
    <tr><td>Build</td><td>2024-01-15</td></tr>
  </tbody>
</Table>

BADGEGROUP
----------
Container for multiple badges with expand/collapse behavior.
Supports data-driven mode with member mappings and legacy array mode.

Props:
  badges?              BadgeItem[] - Legacy badge array
  data?                T[] - Generic data array
  displayValueMember?  string ('label') - Property for display text
  variantMember?       string ('variant') - Property for badge variant
  pillMember?          string ('pill') - Property for pill flag
  sizeMember?          string ('size') - Property for size
  idMember?            string ('id') - Property for unique key
  getDisplayValueCallback? (item: T) => string
  getVariantCallback?  (item: T) => BadgeVariant | undefined
  getPillCallback?     (item: T) => boolean
  getSizeCallback?     (item: T) => BadgeSize | undefined
  limit?               number (5) - Max visible before "N more"
  isShowAll?           boolean (false) - Show all without limit
  onbadgeclick?        (item: T, event: MouseEvent) => void
  class?               string
  children?            Snippet

Data-driven mode:

<script>
  const tags = [
    { id: 1, name: 'JavaScript', type: 'primary' },
    { id: 2, name: 'TypeScript', type: 'info' },
    { id: 3, name: 'Svelte', type: 'success' },
  ];
</script>

<BadgeGroup
  data={tags}
  displayValueMember="name"
  variantMember="type"
  limit={5}
  onbadgeclick={(tag) => console.log(tag.name)}
/>

Legacy mode:

<BadgeGroup badges={[
  { label: 'Active', variant: 'success' },
  { label: 'Draft', variant: 'warning' },
  { label: 'Archived', variant: 'secondary' }
]} />

Snippet mode (manual):

<BadgeGroup>
  <Badge variant="primary">Tag 1</Badge>
  <Badge variant="success">Tag 2</Badge>
</BadgeGroup>

TIMELINE / TIMELINEITEM
-----------------------
Timeline component with three variants: simple, alternating, feed.
Supports data-driven mode, legacy array mode, and snippet mode.

Timeline Props:
  variant?       'simple' | 'alternating' | 'feed' (default: 'simple')
  side?          'start' | 'end' - Put every item on one side (alternating; omit = zig-zag)
  isKeepLayout?  boolean (false) - Keep desktop layout on mobile (alternating)
  isSingleColumn? boolean (false) - Force a single column at any width (alternating)
  data?          T[] - Generic data array
  items?         TimelineItemData[] - Legacy mode
  class?         string

  Member mappings (for data mode):
    variantMember?    string ('variant')
    filledMember?     string ('filled')
    dateHeaderMember? string
    timeMember?       string ('time')
    dateMember?       string ('date')
    iconTextMember?   string ('iconText')
    avatarUrlMember?  string ('avatarUrl')
    avatarAltMember?  string
    contentMember?    string ('content')
    commentMember?    string ('comment')
    idMember?         string ('id')

  Callbacks:
    getVariantCallback?   (item: T) => TimelineItemVariant | undefined
    getContentCallback?   (item: T) => string
    (also getFilledCallback, getDateHeaderCallback, getTimeCallback, getDateCallback,
     getIconTextCallback, getAvatarUrlCallback, getAvatarAltCallback, getCommentCallback)

  Template snippets:
    iconTemplate?     Snippet<[T]> - Custom icon per item

  onclick?       (event: MouseEvent) => void
  class?         string

COMPLETE TABLE PAGE EXAMPLE
----------------------------
Putting it all together: filter card + table card + pager + detail view.

<script>
  import {
    Card, FilterCard, TableCard, Table, Badge, Button,
    Pager, DetailView, DetailPanel, Fields, Field, Input, Select, Grid
  } from '@keenmate/svelte-pure-admin';

  let page = $state(1);
  let showDetail = $state(false);
  let selectedItem = $state(null);
  let search = $state('');
  let status = $state('');

  const users = [
    { id: 1, name: 'Alice', email: 'alice@co.com', role: 'Admin', active: true },
    { id: 2, name: 'Bob', email: 'bob@co.com', role: 'User', active: false },
  ];
</script>

<DetailView bind:isOpen={showDetail} onclose={() => showDetail = false}>
  {#snippet main()}
    <FilterCard onclear={() => { search = ''; status = ''; }} onrefresh={() => {}}>
      {#snippet filters()}
        <Input placeholder="Search users..." bind:value={search} />
        <Select bind:value={status}>
          <option value="">All Statuses</option>
          <option value="active">Active</option>
          <option value="inactive">Inactive</option>
        </Select>
      {/snippet}
    </FilterCard>

    <TableCard titleText="Users">
      {#snippet actions()}
        <Button variant="primary" size="sm">Add User</Button>
      {/snippet}

      <Table isStriped>
        <thead>
          <tr><th>Name</th><th>Email</th><th>Role</th><th>Status</th></tr>
        </thead>
        <tbody>
          {#each users as user}
            <tr onclick={() => { selectedItem = user; showDetail = true; }}>
              <td>{user.name}</td>
              <td>{user.email}</td>
              <td>{user.role}</td>
              <td>
                <Badge variant={user.active ? 'success' : 'danger'}>
                  {user.active ? 'Active' : 'Inactive'}
                </Badge>
              </td>
            </tr>
          {/each}
        </tbody>
      </Table>

      {#snippet footer()}
        <Pager bind:currentPage={page} totalPages={10} />
      {/snippet}
    </TableCard>
  {/snippet}

  <DetailPanel titleText={selectedItem?.name ?? ''} onclose={() => showDetail = false}>
    <Fields cols={2} layout="horizontal" isBordered>
      <Field labelText="Name" valueText={selectedItem?.name} />
      <Field labelText="Email" valueText={selectedItem?.email} copyMode="hover" />
      <Field labelText="Role" valueText={selectedItem?.role} />
    </Fields>
  </DetailPanel>
</DetailView>

CRITICAL REMINDERS
------------------
- Always import CSS: import '@keenmate/pure-admin-core/css'
- Use Svelte 5 runes: $props(), $state(), $derived(), $bindable()
- Content uses Snippets ({#snippet name()}...{/snippet}), NOT <slot>
- Event handlers are lowercase: onclick, onclose, onchange (NOT onClick)
- Boolean props use is* prefix: isGhost, isStriped, isCompact
- Show-a-part flags use has* prefix: hasToggle, hasClear; behaviour flags use should*: shouldCloseOnEscape
- Class prop pattern: class?: string with let { class: className = '' } = $props()
- Card body has padding by default (hasPadding=true), TableCard has none
- TableCard is preferred over Card for tables (proper padding alignment)
- Pager currentPage is bindable
- DetailView isOpen is bindable
- FilterCard isExpanded is bindable
