INTERNATIONALIZATION (i18n)
===========================

CRITICAL: This library uses svelte-i18n under the hood, NOT a custom solution.
All i18n functionality auto-initializes on import -- no setup required for defaults.
Built-in locales: English (en) and Czech (cs), both bundled and auto-registered.
All library component strings (close buttons, aria labels, dialog text) use $_().

INSTALLATION
------------
No separate i18n package needed. It is part of @keenmate/svelte-pure-admin.

npm install @keenmate/svelte-pure-admin


ZERO-CONFIG USAGE (JUST WORKS)
-------------------------------
Built-in translations load automatically when you import anything from the library.
No init() call needed for basic English usage:

<script>
  import { _, Modal } from '@keenmate/svelte-pure-admin';

  let isSettingsOpen = $state(false);
</script>

<!-- All component strings (close buttons, aria labels) already translated -->
<Modal titleText="Settings" bind:isOpen={isSettingsOpen}>
  <p>Content here</p>
</Modal>

<!-- Use $_ for your own translation keys -->
<p>{$_('pureAdmin.buttons.cancel')}</p>
<!-- Output: "Cancel" -->


I18N SERVICE API
----------------
The i18n service is the primary API for managing languages and locales.
It is a Svelte 5 reactive singleton using runes ($state, $derived).

Import:
import { i18n } from '@keenmate/svelte-pure-admin';

Properties (reactive getters):
  i18n.currentLocale     -- Current active locale code (string)
  i18n.languages         -- Available languages list (Language[])
  i18n.isLoading         -- True while loading translations async (boolean)
  i18n.fallbackLocale    -- Fallback locale code (string)
  i18n.loadedLocales     -- Set of loaded locale codes (Set<string>)

Methods:
  i18n.init(options)              -- Initialize with options (see below)
  i18n.setLocale(code)            -- Switch locale (async, loads if needed)
  i18n.getLanguage(code)          -- Get Language object by code
  i18n.isLocaleLoaded(code)       -- Check if locale translations are loaded
  i18n.setLanguages(langs)        -- Replace entire languages list
  i18n.addLanguage(lang)          -- Add a language to available list
  i18n.removeLanguage(code)       -- Remove a language from list
  i18n.addTranslations(code, obj) -- Add translations for a locale
  i18n.setTranslationLoader(fn)   -- Set async loader function


INIT OPTIONS
------------
interface I18nInitOptions {
  locale?: string;                                      // Initial locale (default: 'en')
  fallbackLocale?: string;                              // Fallback (default: 'en')
  languages?: (string | Language)[];                    // Available languages
  translations?: Record<string, Record<string, string>>; // Pre-loaded translations
  loadTranslations?: (locale: string) => Promise<Record<string, string>>; // Async loader
}

interface Language {
  code: string;        // e.g., 'en', 'cs', 'de'
  name?: string;       // e.g., 'English', 'Czech'
  nativeName?: string; // e.g., 'English', 'Cestina'
}


BASIC SETUP WITH CUSTOM LOCALE
-------------------------------
import { i18n } from '@keenmate/svelte-pure-admin';

// Set locale to Czech (built-in, no loading needed)
i18n.init({
  locale: 'cs',
  fallbackLocale: 'en'
});

Result: All library components now show Czech text.
  $_('pureAdmin.dialog.confirm') --> "Potvrdit"
  $_('pureAdmin.buttons.cancel')  --> "Zrušit"


SWITCHING LOCALES AT RUNTIME
-----------------------------
import { i18n } from '@keenmate/svelte-pure-admin';

// Switch to a loaded locale (instant)
await i18n.setLocale('cs');

// Switch to an unloaded locale (triggers async loader if configured)
await i18n.setLocale('de');

Language picker component example:

<script>
  import { i18n, _ } from '@keenmate/svelte-pure-admin';

  async function handleChange(event) {
    await i18n.setLocale(event.target.value);
  }
</script>

<select value={i18n.currentLocale} onchange={handleChange} disabled={i18n.isLoading}>
  {#each i18n.languages as lang}
    <option value={lang.code}>{lang.name || lang.code}</option>
  {/each}
</select>

{#if i18n.isLoading}
  <span>{$_('pureAdmin.loadMore.loading')}</span>
{/if}


ADDING A NEW LANGUAGE (INJECTED)
---------------------------------
Provide translations at init time:

import { i18n } from '@keenmate/svelte-pure-admin';

i18n.init({
  locale: 'de',
  fallbackLocale: 'en',
  languages: [
    { code: 'en', name: 'English' },
    { code: 'de', name: 'Deutsch' },
    { code: 'cs', name: 'Czech', nativeName: 'Cestina' }
  ],
  translations: {
    de: {
      'pureAdmin.dialog.confirm': 'Bestatigen',
      'pureAdmin.buttons.cancel': 'Abbrechen',
      'pureAdmin.buttons.ok': 'OK',
      'pureAdmin.dialog.alert': 'Warnung',
      'pureAdmin.dialog.areYouSure': 'Sind Sie sicher?',
      'pureAdmin.buttons.close': 'Schliessen',
      // ... your app translations
      'app.dashboard.title': 'Ubersicht',
      'app.users.count': '{count} Benutzer'
    }
  }
});

Or add translations after init:

import { i18n } from '@keenmate/svelte-pure-admin';

i18n.addLanguage({ code: 'fr', name: 'Francais' });
i18n.addTranslations('fr', {
  'pureAdmin.dialog.confirm': 'Confirmer',
  'pureAdmin.buttons.cancel': 'Annuler',
  'pureAdmin.buttons.close': 'Fermer',
  'app.dashboard.title': 'Tableau de bord'
});

await i18n.setLocale('fr');


LAZY LOADING LOCALES (ASYNC)
------------------------------
Load translations on demand from an API or static files:

import { i18n } from '@keenmate/svelte-pure-admin';

i18n.init({
  locale: 'en',
  languages: [
    { code: 'en', name: 'English' },
    { code: 'de', name: 'Deutsch' },
    { code: 'fr', name: 'Francais' }
  ],
  translations: {
    en: { /* bundled english translations */ }
  },
  loadTranslations: async (locale) => {
    const res = await fetch(`/api/translations/${locale}`);
    return res.json();
  }
});

// Later, when user switches:
await i18n.setLocale('de');
// 1. Checks if 'de' is loaded -> No
// 2. Calls loadTranslations('de')
// 3. Adds messages via addMessages()
// 4. Switches locale

Or set the loader after init:

i18n.setTranslationLoader(async (locale) => {
  const module = await import(`./locales/${locale}.json`);
  return module.default;
});


OVERRIDING LIBRARY TRANSLATIONS
---------------------------------
Override built-in component strings without replacing everything:

Method 1: Via init translations
import { i18n } from '@keenmate/svelte-pure-admin';

i18n.init({
  locale: 'en',
  translations: {
    en: {
      'pureAdmin.dialog.confirm': 'Yes, do it!',
      'pureAdmin.buttons.cancel': 'Nope',
      'pureAdmin.field.clickToCopy': 'Copy this value',
      'pureAdmin.field.copied': 'Done!'
    }
  }
});

Method 2: Via registerLibraryTranslations (backwards compatible)
import { registerLibraryTranslations } from '@keenmate/svelte-pure-admin';

registerLibraryTranslations('en', {
  'pureAdmin.dialog.confirm': 'Yes, do it!',
  'pureAdmin.buttons.close': 'Dismiss'
});

Method 3: Via addMessages (svelte-i18n direct)
import { addMessages } from '@keenmate/svelte-pure-admin';

addMessages('en', {
  'pureAdmin.dialog.confirm': 'Confirm action',
  'pureAdmin.popconfirm.confirm': 'Do it'
});


TRANSLATION STORE ($_)
-----------------------
The $_ store is re-exported from svelte-i18n for convenience.
Always import from @keenmate/svelte-pure-admin (not svelte-i18n directly)
to ensure auto-initialization runs first.

import { _ } from '@keenmate/svelte-pure-admin';

<!-- In Svelte template -->
<p>{$_('pureAdmin.dialog.areYouSure')}</p>
<p>{$_('app.greeting', { values: { name: 'John' } })}</p>

All library translation keys use the 'pureAdmin.' namespace prefix.

COMPLETE APP SETUP EXAMPLE
---------------------------
// src/lib/i18n-setup.ts
import { i18n } from '@keenmate/svelte-pure-admin';

export function setupI18n() {
  i18n.init({
    locale: 'en',
    fallbackLocale: 'en',
    languages: [
      { code: 'en', name: 'English' },
      { code: 'cs', name: 'Czech', nativeName: 'Cestina' },
      { code: 'de', name: 'German', nativeName: 'Deutsch' }
    ],
    translations: {
      en: {
        'app.dashboard.title': 'Dashboard',
        'app.users.title': 'Users',
        'app.settings.title': 'Settings'
      },
      cs: {
        'app.dashboard.title': 'Prehled',
        'app.users.title': 'Uzivatele',
        'app.settings.title': 'Nastaveni'
      }
    },
    loadTranslations: async (locale) => {
      // German loaded on demand
      const res = await fetch(`/locales/${locale}.json`);
      return res.json();
    }
  });
}

// src/routes/+layout.svelte
<script>
  import { setupI18n } from '$lib/i18n-setup';
  import '@keenmate/pure-admin-core/css';

  let { children } = $props();

  setupI18n();
</script>

{@render children()}

// src/routes/+page.svelte
<script>
  import { _, i18n, Button, Card } from '@keenmate/svelte-pure-admin';

<Card titleText={$_('app.dashboard.title')}>

  {/each}

CRITICAL REMINDERS
------------------
- Always import $_, locale, locales, isLoading from @keenmate/svelte-pure-admin (NOT from svelte-i18n directly)
- Auto-initialization ensures translations work even without calling i18n.init()
- Built-in en and cs locales are always registered automatically
- All library keys use flat format: 'pureAdmin.dialog.confirm' (not nested objects)
- The i18n service is a Svelte 5 reactive singleton (properties update automatically)
- The $_ store returns a function: use $_('key') in templates
- Translations merge additively -- calling addTranslations/addMessages never removes existing keys
- When a key is missing, svelte-i18n falls back to fallbackLocale (default: 'en')
