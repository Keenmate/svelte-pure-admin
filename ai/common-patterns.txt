COMMON PATTERNS
===============

CRITICAL: This is a Svelte 5 component library. ALL components use runes ($props, $state, $derived).
Never use legacy Svelte syntax (export let, $:, <slot>).
All CSS classes follow BEM naming: pa-[block]__[element]--[modifier].


1. SNIPPET PATTERN (REPLACES SLOTS)
-------------------------------------
Svelte 5 replaces <slot> with {#snippet} blocks and {@render}.
Components declare snippets as Snippet type props.

Simple card with text title:

<Card titleText="My Card">
  <p>This is the body content (children snippet).</p>
</Card>

Card with all snippet sections:

<Card titleText="User Details">
  {#snippet header()}
    <h3>Custom Header Content</h3>
  {/snippet}

  <p>Body content goes here as children.</p>

  {#snippet footer()}
    <Button variant="primary">Save Changes</Button>
    <Button variant="secondary" isOutline>Cancel</Button>
  {/snippet}
</Card>

Card with tools (actions in header):

<Card titleText="Orders">
  {#snippet tools()}
    <Button size="sm" variant="primary">Add New</Button>
    <Button size="sm" variant="secondary" isOutline>Export</Button>
  {/snippet}

  <Table isStriped>...</Table>
</Card>

Card with title icon:

<Card titleText="Analytics">
  {#snippet titleIcon()}
    <svg>...</svg>
  {/snippet}

  <p>Dashboard content</p>
</Card>

Modal with header, body, footer:

<Modal bind:isOpen={isOpen} titleText="Confirm Delete">
  <p>Are you sure you want to delete this item?</p>

  {#snippet footer()}
    <Button variant="danger" onclick={handleDelete}>Delete</Button>
    <Button variant="secondary" isOutline onclick={() => isOpen = false}>Cancel</Button>
  {/snippet}
</Modal>

3. CLASS BUILDING ($derived PATTERN)
-------------------------------------
Every component uses $derived() with a function for dynamic class strings.
This is the standard pattern -- replicate it in your own components.

Component internal pattern:

<script lang="ts">
  interface Props {
    variant?: 'primary' | 'secondary' | 'success' | 'danger';
    size?: 'sm' | 'lg';
    isOutline?: boolean;
    isBlock?: boolean;
    class?: string;
    children?: import('svelte').Snippet;
  }

  let {
    variant = 'primary',
    size,
    isOutline = false,
    isBlock = false,
    class: className = '',
    children
  }: Props = $props();

  const classes = $derived(() => {
    const base = ['pa-component'];
    if (isOutline) {
      base.push(`pa-component--outline-${variant}`);
    } else {
      base.push(`pa-component--${variant}`);
    }
    if (size) base.push(`pa-component--${size}`);
    if (isBlock) base.push('pa-component--block');
    if (className) base.push(className);
    return base.join(' ');
  });
</script>

<div class={classes()}>
  {@render children?.()}
</div>

IMPORTANT: classes is a FUNCTION -- use class={classes()} not class={classes}.


4. EVENT HANDLERS (LOWERCASE, NATIVE DOM STYLE)
-------------------------------------------------
Svelte 5 uses lowercase event handlers matching native DOM events.
Use shorthand {onclick} when prop name matches attribute.

Button click:

<Button onclick={() => console.log('clicked')}>Click Me</Button>
<Button onclick={handleSave} variant="success">Save</Button>

Modal close:

<Modal
  bind:isOpen={showModal}
  titleText="Confirm"
  onclose={() => console.log('modal closed')}
>
  <p>Are you sure?</p>
</Modal>

Input events:

<Input
  bind:value={search}
  oninput={(e) => handleSearch(e.currentTarget.value)}
  onblur={() => touched = true}
  onfocus={() => console.log('focused')}
  onkeydown={(e) => { if (e.key === 'Enter') submit(); }}
/>

Prevent close with callback:

<Modal
  bind:isOpen={showForm}
  beforeCloseCallback={() => {
    if (hasUnsavedChanges) {
      return false; // Prevents closing
    }
  }}
  onclose={() => resetForm()}
>
  ...
</Modal>

Form with validation errors (using errors/isTouched props):

<script>
  let email = $state('');
  let password = $state('');
  let touchedFields = $state({ email: false, password: false });
  let errors = $state({ email: [], password: [] });

  function validate() {
    errors.email = !email ? ['Email is required'] : [];
    errors.password = password.length < 8 ? ['Password must be 8+ characters'] : [];
  }
</script>

<Form>
  <FormGroup validation={touchedFields.email && errors.email.length ? 'error' : undefined} isRequired>
    <FormLabel>Email</FormLabel>
    <Input
      bind:value={email}
      type="email"
      errors={errors.email}
      isTouched={touchedFields.email}
      onblur={() => { touchedFields.email = true; validate(); }}
    />
  </FormGroup>

  <FormGroup validation={touchedFields.password && errors.password.length ? 'error' : undefined} isRequired>
    <FormLabel>Password</FormLabel>
    <Input
      bind:value={password}
      type="password"
      errors={errors.password}
      isTouched={touchedFields.password}
      onblur={() => { touchedFields.password = true; validate(); }}
    />
  </FormGroup>

  <Button type="submit" variant="primary">Sign In</Button>
</Form>

10. TOAST NOTIFICATIONS
------------------------

Basic toast setup:

<script>
  let toasts = $state([]);

  function addToast(variant, title, message) {
    toasts = [...toasts, { id: Date.now(), variant, title, message, show: true }];
  }

  function removeToast(id) {
    toasts = toasts.filter(t => t.id !== id);
  }
</script>

<Button onclick={() => addToast('success', 'Saved', 'Changes saved.')}>Show Toast</Button>

<ToastContainer placement="top-end">
  {#each toasts as toast (toast.id)}
    <Toast
      variant={toast.variant}
      titleText={toast.title}
      messageText={toast.message}
      bind:isVisible={toast.show}
      onclose={() => removeToast(toast.id)}
    />
  {/each}
</ToastContainer>

Toast with progress bar:

<Toast
  variant="info"
  titleText="Processing"
  messageText="Your file is being uploaded..."
  hasProgress
  duration={10000}
/>

11. DIALOG SERVICE (PROGRAMMATIC)
----------------------------------
Promise-based dialogs -- no component placement needed (just DialogContainer).

Setup (once in layout):

<script>
  import { DialogContainer } from '@keenmate/svelte-pure-admin';
</script>

<DialogContainer />

Usage anywhere in app:

<script>
  import { dialogService } from '@keenmate/svelte-pure-admin';

  async function handleDelete() {
    const confirmed = await dialogService.confirm({
      title: 'Delete Item?',
      message: 'This action cannot be undone.',
      variant: 'danger',
      confirmText: 'Delete',
      cancelText: 'Keep It'
    });

    if (confirmed) {
      await deleteItem();
    }
  }

  async function showAlert() {
    await dialogService.alert({
      title: 'Success!',
      message: 'The operation completed.',
      variant: 'success'
    });
  }

  async function askForName() {
    const name = await dialogService.prompt({
      title: 'Enter Name',
      message: 'What should we call this item?',
      placeholder: 'Item name...',
      validator: (value) => value.length >= 3 ? true : 'Name must be 3+ characters'
    });

    if (name !== null) {
      // User submitted a value
      console.log('Name:', name);
    }
  }

  async function customDialog() {
    const result = await dialogService.custom({
      title: 'Choose Action',
      message: 'What would you like to do with this file?',
      buttons: [
        { label: 'Download', value: 'download', variant: 'primary' },
        { label: 'Share', value: 'share', variant: 'info', isOutline: true },
        { label: 'Delete', value: 'delete', variant: 'danger', isOutline: true },
        { label: 'Cancel', value: 'cancel', variant: 'secondary' }
      ],
      dismissValue: 'cancel'
    });

    if (result === 'download') { /* ... */ }
  }
</script>

18. BATCH RPC (MULTIPLE API CALLS IN ONE REQUEST)
---------------------------------------------------

<script>
  import { createBatch, createHttpTransport, pureDataConfig } from '@keenmate/svelte-pure-admin';

  const transport = createHttpTransport('/api/rpc/batch', pureDataConfig, {
    getHeaders: () => ({
      'Authorization': `Bearer ${authToken}`
    })
  });

  async function loadDashboard() {
    const batch = createBatch(transport);

    const stats = batch.add('dashboard.getStats');
    const users = batch.add('users.getRecent', { limit: 10 });
    const orders = batch.add('orders.getRecent', { limit: 5 });

    await batch.execute(); // 1 HTTP request instead of 3

    dashboardStats = await stats;
    recentUsers = await users;
    recentOrders = await orders;
  }
</script>


CRITICAL REMINDERS
-------------------
- Svelte 5 ONLY: $props(), $state(), $derived(), $bindable(), $effect()
- NO legacy: no 'export let', no '$:', no '<slot>'
- Snippets replace slots: {#snippet name()}...{/snippet}, {@render name?.()}
- Event handlers: lowercase on* (onclick, onclose, not onClick, onClose)
- Class building: $derived(() => { ... }) returns a FUNCTION, use class={classes()}
- BEM classes: pa-[block]__[element]--[modifier]
- RTL-aware: use start/end not left/right (toast positions, alignment)
