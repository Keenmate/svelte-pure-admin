TYPESCRIPT TYPES
================

CRITICAL: All components use TypeScript interfaces for props.
All types are exported from '@keenmate/svelte-pure-admin'.
This file contains every exported type definition so AI assistants know exact valid values.


CORE TYPES (types.ts)
---------------------
Source: packages/svelte-pure-admin/src/lib/types.ts

Color variants used across most components:

  type ColorVariant =
    | 'primary'
    | 'secondary'
    | 'success'
    | 'danger'
    | 'warning'
    | 'info'
    | 'light'
    | 'dark';

Standard size variants:

  type Size = 'xs' | 'sm' | 'lg' | 'xl';

Extended size (includes 2xl for layouts):

  type ExtendedSize = 'xs' | 'sm' | 'lg' | 'xl' | '2xl';

Horizontal alignment (logical, RTL-aware since v1.5.0):

  type HorizontalAlignment = 'start' | 'center' | 'end';

Vertical alignment:

  type VerticalAlignment = 'start' | 'center' | 'end' | 'stretch' | 'baseline';

Text mode:

  type TextMode = 'default' | 'muted';

Form validation state:

  type ValidationState = 'default' | 'success' | 'warning' | 'error';

Data visualization color variants (subset of ColorVariant):

  type DataVizVariant = 'success' | 'warning' | 'danger' | 'info';

Theme colors (numbered 1-9 for color palettes):

  type ThemeColor = 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9;

SHORTCUT REGISTRY TYPES (shortcut-registry-types.ts)
------------------------------------------------------
Source: packages/svelte-pure-admin/src/lib/services/shortcut-registry-types.ts

  interface ShortcutModifiers {
    ctrl?: boolean;
    shift?: boolean;
    alt?: boolean;
    meta?: boolean;
  }

  interface Shortcut {
    id: string;
    key: string;
    modifiers?: ShortcutModifiers;
    description: string;
    category?: string;
    action: () => void;
    enabled?: boolean;
    scope?: ShortcutScope;
    priority?: number;
  }

  type ShortcutScope =
    | 'global'    // Always active (except in inputs)
    | 'modal'     // Only active when a modal is open
    | 'input'     // Only active when focused in an input
    | string;     // Custom scope

  type ShortcutRegistration = Omit<Shortcut, 'enabled'> & {
    enabled?: boolean;
  };

  interface ShortcutRegistry {
    register(shortcut: ShortcutRegistration): () => void;  // Returns unregister fn
    unregister(id: string): void;
    enable(id: string): void;
    disable(id: string): void;
    getAll(): Shortcut[];
    getByCategory(): Map<string, Shortcut[]>;
    handleKeyDown(event: KeyboardEvent): void;
    has(id: string): boolean;
    readonly all: Shortcut[];                    // Reactive getter
    readonly byCategory: Map<string, Shortcut[]>; // Reactive getter
    readonly count: number;                       // Reactive getter
  }

Import example:

  import { shortcutRegistry, formatShortcut } from '@keenmate/svelte-pure-admin';

  import type {
    Shortcut,
    ShortcutModifiers,
    ShortcutScope,

Phoenix transport:

  interface PhoenixChannel {
    push(event: string, payload: object): {
      receive(status: 'ok', callback: (response: unknown) => void): PhoenixPush;
      receive(status: 'error', callback: (response: unknown) => void): PhoenixPush;
      receive(status: 'timeout', callback: () => void): PhoenixPush;
    };
  }

  interface PhoenixPush {
    receive(status: 'ok', callback: (response: unknown) => void): PhoenixPush;
    receive(status: 'error', callback: (response: unknown) => void): PhoenixPush;
    receive(status: 'timeout', callback: () => void): PhoenixPush;
  }

  interface PhoenixTransportOptions {
    eventName?: string;              // default: "batch_invoke"
    timeout?: number;                // default: 30000
    getRequestMetadata?: () => Record<string, unknown> | Promise<Record<string, unknown>>;
  }

  function createPhoenixTransport(
    channel: PhoenixChannel,
    config: RpcTransportConfig,
    options?: PhoenixTransportOptions
  ): RpcTransport;

HTTP transport:

    onBeforeRequest?: (request: BatchRequest, init: RequestInit) => void | Promise<void>;

CRITICAL REMINDERS
-------------------
- All types are exported from the main '@keenmate/svelte-pure-admin' package
- Use 'import type' for type-only imports (TypeScript best practice)
- ColorVariant has 8 values: primary, secondary, success, danger, warning, info, light, dark
- Size has 4 values: xs, sm, lg, xl (no 'md' -- that is the default)
- ThemeColor is a number 1-9, not a string
- HorizontalAlignment uses logical start/end (not left/right) for RTL support
- ToastPlacement uses logical start/end (top-end, not top-right) for RTL support
- DialogButton value is generic <T> -- can be any type
- Command palette supports both sync and async getOptions/onSearch (Promise | direct)
- Batch.add<T>() is generic -- specify the expected return type for type safety
- Snippet type is: import('svelte').Snippet (from svelte module)
