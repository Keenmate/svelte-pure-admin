TYPESCRIPT TYPES
================

CRITICAL: All components use TypeScript interfaces for props.
All types are exported from '@keenmate/svelte-pure-admin'.
This file contains every exported type definition so AI assistants know exact valid values.


CORE TYPES (types.ts)
---------------------
Source: packages/svelte-pure-admin/src/lib/types.ts

Color variants used across most components:

  type ColorVariant =
    | 'primary'
    | 'secondary'
    | 'success'
    | 'danger'
    | 'warning'
    | 'info'
    | 'light'
    | 'dark';

Standard size variants:

  type Size = 'xs' | 'sm' | 'lg' | 'xl';

Extended size (includes 2xl for layouts):

  type ExtendedSize = 'xs' | 'sm' | 'lg' | 'xl' | '2xl';

Horizontal alignment (logical, RTL-aware since v1.5.0):

  type HorizontalAlignment = 'start' | 'center' | 'end';

Vertical alignment:

  type VerticalAlignment = 'start' | 'center' | 'end' | 'stretch' | 'baseline';

Form validation state:

  type ValidationState = 'default' | 'success' | 'warning' | 'error';

Data visualization color variants (subset of ColorVariant; 'primary' = base fill, no modifier):

  type DataVizVariant = 'primary' | 'success' | 'warning' | 'danger' | 'info';

Tooltip placement / mode / variant (shared by <Tooltip> and Card title/description tooltips):

  type TooltipPlacement = 'top' | 'end' | 'bottom' | 'start';   // logical, flips in RTL
  type TooltipMode = 'overflow' | 'always';  // overflow = only while text is truncated (default)
  type TooltipVariant = 'primary' | 'success' | 'warning' | 'danger'
    | 'color-1' | 'color-2' | 'color-3' | 'color-4' | 'color-5'
    | 'color-6' | 'color-7' | 'color-8' | 'color-9';

Theme colors (numbered 1-9 for color palettes):

  type ThemeColor = 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9;

Import example:

    Size,
    ExtendedSize,
    HorizontalAlignment,
    VerticalAlignment,
    ValidationState,
    DataVizVariant,
    ThemeColor,
    TooltipPlacement,
    TooltipMode,
    TooltipVariant
  } from '@keenmate/svelte-pure-admin';


ICON PROVIDER TYPES (icon/)
----------------------------
Source: packages/svelte-pure-admin/src/lib/icon/icon-provider.ts, providers.ts, affordances.ts

  interface IconRenderContext {
    class?: string;
    size?: string;            // CSS length, e.g. '1.25rem'
    isInteractive?: boolean;  // standalone hover affordance (.pc-icon-hover)
    label?: string;
  }

  // Returns markup for `name`, or '' so the next provider gets a turn
  type IconProvider = (name: string, ctx: IconRenderContext) => string;

  interface FontAwesomeOptions {
    style?: string;        // 'fa-solid' (default), 'fa-regular', 'fas', ...
    fixedWidth?: boolean;  // default true (fa-fw)
  }

  interface SvgIconsOptions {
    viewBox?: string;              // default '0 0 24 24'
    fill?: string;                 // default 'none'
    stroke?: string;               // default 'currentColor'
    strokeWidth?: number | string; // default 2
    hoverMarker?: string;          // default 'pc-icon-hover-highlight'
  }

  type AffordanceIconName = (typeof AFFORDANCE_ICON_NAMES)[number];  // masked pa-icon--* names

Provider factories / helpers:

  masked(): IconProvider;            // affordance names -> <span class="pa-icon pa-icon--NAME">
  fontAwesome(options?: FontAwesomeOptions): IconProvider;
  svgIcons(paths: Record<string, string>, options?: SvgIconsOptions): IconProvider;
  combine(...providers: IconProvider[]): IconProvider;   // first non-empty result wins
  setIconProviders, useIconProviders, resolveIcon, AFFORDANCE_ICON_NAMES, isAffordanceIcon

  interface ShortcutModifiers {
    ctrl?: boolean;
    shift?: boolean;
    alt?: boolean;
    meta?: boolean;
  }

  interface Shortcut {
    id: string;
    key: string;
    modifiers?: ShortcutModifiers;
    description: string;
    category?: string;
    action: () => void;
    enabled?: boolean;
    scope?: ShortcutScope;
    priority?: number;
  }

  type ShortcutScope =
    | 'global'    // Always active (except in inputs)
    | 'modal'     // Only active when a modal is open
    | 'input'     // Only active when focused in an input
    | string;     // Custom scope

  type ShortcutRegistration = Omit<Shortcut, 'enabled'> & {
    enabled?: boolean;
  };

  interface ShortcutRegistry {
    register(shortcut: ShortcutRegistration): () => void;  // Returns unregister fn
    unregister(id: string): void;
    enable(id: string): void;
    disable(id: string): void;
    getAll(): Shortcut[];
    getByCategory(): Map<string, Shortcut[]>;
    handleKeyDown(event: KeyboardEvent): void;
    has(id: string): boolean;
    readonly all: Shortcut[];                    // Reactive getter
    readonly byCategory: Map<string, Shortcut[]>; // Reactive getter
    readonly count: number;                       // Reactive getter
  }

CRITICAL REMINDERS
-------------------
- All types are exported from the main '@keenmate/svelte-pure-admin' package
- Use 'import type' for type-only imports (TypeScript best practice)
- ColorVariant has 8 values: primary, secondary, success, danger, warning, info, light, dark
- Size has 4 values: xs, sm, lg, xl (no 'md' -- that is the default)
- ThemeColor is a number 1-9, not a string
- HorizontalAlignment uses logical start/end (not left/right) for RTL support
- ToastPlacement uses logical start/end (top-end, not top-right) for RTL support
- Placement types are *Placement (TooltipPlacement, ModalPlacement, DialogPlacement, ToastPlacement);
  there are no *Position types and no TextMode / LoaderColor / RangeHandleShape types
- DialogButton value is generic <T> -- can be any type
- Command palette supports both sync and async getOptions/onSearch (Promise | direct)
- Batch.add<T>() is generic -- specify the expected return type for type safety
- Snippet type is: import('svelte').Snippet (from svelte module)
