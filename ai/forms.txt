FORM COMPONENTS
===============

CRITICAL: This is a Svelte 5 component library (@keenmate/svelte-pure-admin).
- All components use Svelte 5 runes ($props, $state, $derived)
- Content sections use Snippets ({#snippet}), NOT slots (<slot>)
- BEM class names internally (pa-*) - you never write CSS classes manually
- Import from '@keenmate/svelte-pure-admin'
- Values are bindable via bind:value, bind:isChecked, bind:group

INSTALLATION
------------
npm install @keenmate/svelte-pure-admin

CSS must be imported once in your app (e.g., +layout.svelte):

<script>
  import '@keenmate/pure-admin-core/css';
</script>


FORM
----
Standard HTML form wrapper. Renders <form class="pa-form">.
Extends HTMLFormAttributes so all native form attributes work (action, method, etc.).

Props:
  class?: string           Additional CSS classes
  children?: Snippet       Form content
  ...HTMLFormAttributes    All native form attributes (action, method, onsubmit, etc.)

<Form onsubmit={handleSubmit}>
  <FormGroup>
    <FormLabel>Name</FormLabel>
    <Input bind:value={name} />
  </FormGroup>
  <Button type="submit">Save</Button>
</Form>

With SvelteKit form action:

<Form method="POST" action="?/save">
  <FormGroup>
    <FormLabel>Email</FormLabel>
    <Input type="email" name="email" bind:value={email} />
  </FormGroup>
  <Button type="submit">Submit</Button>
</Form>


FORM GROUP
----------
Form group wrapper for label + input + help text. Renders <div class="pa-form-group">.
Handles validation state styling and horizontal layout.

Props:
  validation?: 'success' | 'warning' | 'error' Validation state (adds pa-form-group--{validation})
  isError?: boolean          Legacy error flag (prefer validation prop)
  isSuccess?: boolean        Legacy success flag (prefer validation prop)
  isRequired?: boolean       Mark as required (adds pa-form-group--required)
  isHorizontal?: boolean     Horizontal layout, label left, input right (default: false)
  horizontal?: boolean       Alias for isHorizontal
  class?: string             Additional CSS classes
  children?: Snippet         Label + input + help content

Basic form group:

<FormGroup>
  <FormLabel>Username</FormLabel>
  <Input bind:value={username} />
</FormGroup>

Required field:

<FormGroup isRequired={true}>
  <FormLabel>Email</FormLabel>
  <Input type="email" bind:value={email} isRequired />
</FormGroup>

With validation state:

<FormGroup validation="error">
  <FormLabel>Password</FormLabel>
  <Input type="password" bind:value={password} validation="error" />
  <FormHelp variant="error">Password is required</FormHelp>
</FormGroup>

<FormGroup validation="success">
  <FormLabel>Username</FormLabel>
  <Input bind:value={username} validation="success" />
  <FormHelp variant="success">Username is available</FormHelp>
</FormGroup>

Horizontal layout:

<FormGroup horizontal>
  <FormLabel>Company</FormLabel>
  <Input bind:value={company} />
</FormGroup>


FORM FIELD
----------
High-level wrapper that combines FormGroup + FormLabel + FormHelp with automatic
error/success state handling. Reduces boilerplate when using form validation.

The children snippet receives context: { errors: string[], touched: boolean, validation?: InputState }

Props:
  labelText?: string            Field label text
  helpText?: string             Default help text (shown when no errors)
  successMessage?: string       Success message (shown when touched, no errors, has value)
  errors?: string[] | null      Error messages from validation
  touched?: boolean             Whether field has been interacted with (default: false)
  hasValue?: boolean            Field has a value (for success state) (default: false)
  validation?: 'success' | 'warning' | 'error'  Manual validation override
  class?: string                Additional class for FormGroup
  horizontal?: boolean          Horizontal layout (default: false)
  children: Snippet<[{ errors, touched, validation }]>    The input control (REQUIRED)

Basic usage:

<FormField labelText="Email">
  {#snippet children()}
    <Input isRequired type="email" bind:value={email} />
  {/snippet}
</FormField>

With validation:

<FormField
  labelText="Username"
  errors={usernameErrors}
  touched={usernameTouched}
  hasValue={username.length > 0}
  successMessage="Username is available"
  helpText="Choose a unique username"
>
  {#snippet children({ errors, touched })}
    <Input isRequired bind:value={username} {errors} {touched} />
  {/snippet}
</FormField>

With manual validation:

<FormField labelText="API Key" validation="warning" helpText="This key expires in 3 days">
  {#snippet children()}
    <Input bind:value={apiKey} validation="warning" />
  {/snippet}
</FormField>

INPUT
-----
Text-like input component. Renders <input class="pa-input">.
For text, email, password, tel, url, search types only.
For numbers use NumberInput. For dates use DateInput.

Props:
  type?: 'text' | 'email' | 'password' | 'tel' | 'url' | 'search'
                                    Input type (default: 'text')
  value?: string (bindable)         Input value (default: '')
  size?: 'xs' | 'sm' | 'lg' | 'xl'    Input size
  validation?: 'success' | 'warning' | 'error'
                                    Validation state (auto-derived from errors if not set)
  errors?: string | string[]        Error messages (auto-sets validation to 'error' when touched)
  touched?: boolean                 Field has been interacted with (default: true)
  themeColor?: 1-9                  Theme color variant
  isDisabled?: boolean              Disabled state (default: false)
  isReadonly?: boolean              Readonly state (default: false)
  isRequired?: boolean              Required field (default: false)
  placeholder?: string             Placeholder text
  id?: string                      Input ID
  name?: string                    Input name
  minlength?: number               Minimum length
  maxlength?: number               Maximum length
  pattern?: string                 Validation pattern
  autocomplete?: string            Browser autocomplete hint
  class?: string                   Additional CSS classes
  oninput?: handler                Input event handler
  onchange?: handler               Change event handler
  onblur?: handler                 Blur event handler
  onfocus?: handler                Focus event handler
  onkeydown?: handler              Keydown event handler

Basic input:

<Input bind:value={name} placeholder="Enter name" />

Different types:

<Input type="email" bind:value={email} placeholder="user@example.com" />
<Input type="password" bind:value={password} autocomplete="current-password" />
<Input type="search" bind:value={query} placeholder="Search..." />
<Input type="tel" bind:value={phone} />
<Input type="url" bind:value={website} />

Sizes:

<Input size="xs" bind:value={v1} placeholder="Extra small" />
<Input size="sm" bind:value={v2} placeholder="Small" />
<Input bind:value={v3} placeholder="Default size" />
<Input size="lg" bind:value={v4} placeholder="Large" />
<Input size="xl" bind:value={v5} placeholder="Extra large" />

Validation states (manual):

<Input bind:value={name} validation="success" />
<Input bind:value={name} validation="warning" />
<Input bind:value={name} validation="error" />

Validation states (auto-derived from errors):

<Input bind:value={email} errors={emailErrors} touched={emailTouched} />

When touched=true and errors has items, validation automatically becomes 'error'.
When touched=false, errors are not shown (no error styling).

Disabled and readonly:

<Input bind:value={locked} isDisabled />
<Input bind:value={display} isReadonly />

With theme color:

<Input bind:value={themed} themeColor={3} />

With constraints:

<Input bind:value={code} minlength={3} maxlength={10} pattern="[A-Z]{3,10}" />

FORM ERROR SUMMARY
------------------
Displays a summary of form validation errors with clickable anchor links.
Renders an Alert (danger variant) with a list of errors.

Props:
  errors: FormErrorItem[]    Array of error objects (REQUIRED)
  show?: boolean             Whether to show the summary (default: true)
  class?: string             Additional CSS class

FormErrorItem: { field: string; id: string; message: string }

The id field is used to create anchor links (#id) that scroll to the error field.

<script lang="ts">
  import type { FormErrorItem } from '@keenmate/svelte-pure-admin';

  let formErrors = $state<FormErrorItem[]>([]);
  let submitted = $state(false);

  function validate() {
    const errors: FormErrorItem[] = [];
    if (!name) errors.push({ field: 'Name', id: 'name-input', message: 'Name is required' });
    if (!email) errors.push({ field: 'Email', id: 'email-input', message: 'Enter a valid email' });
    formErrors = errors;
    submitted = true;
    return errors.length === 0;
  }
</script>

<FormErrorSummary errors={formErrors} show={submitted && formErrors.length > 0} />

<FormGroup>
  <FormLabel>Name</FormLabel>
  <Input id="name-input" bind:value={name} />
</FormGroup>

<FormGroup>
  <FormLabel>Email</FormLabel>
  <Input id="email-input" type="email" bind:value={email} />
</FormGroup>


VALIDATION PATTERN: ERRORS + TOUCHED
--------------------------------------
All input components (Input, NumberInput, DateInput, Textarea, Select) support
the errors + touched pattern for automatic validation styling.

HOW IT WORKS:
1. Pass errors (string or string[]) and touched (boolean) to the input
2. When touched=true AND errors has items, validation auto-becomes 'error'
3. When touched=false, no error styling is shown (even if errors exist)
4. Manual validation prop always takes precedence over the auto-derived value

<script lang="ts">
  let email = $state('');
  let emailTouched = $state(false);

  // Derive errors from value
  const emailErrors = $derived(() => {
    if (!email) return ['Email is required'];
    if (!email.includes('@')) return ['Invalid email format'];
    return [];
  });
</script>

<FormGroup validation={emailTouched && emailErrors().length > 0 ? 'error' : undefined}>
  <FormLabel>Email</FormLabel>
  <Input isRequired
    type="email"
    bind:value={email}
    errors={emailErrors()}
    touched={emailTouched}
    onblur={() => emailTouched = true}
    placeholder="user@example.com"
  />
  {#if emailTouched && emailErrors().length > 0}
    <FormHelp variant="error">{emailErrors()[0]}</FormHelp>
  {/if}
</FormGroup>

SIMPLIFIED WITH FORM FIELD:

<FormField
  labelText="Email"
  errors={emailErrors()}
  touched={emailTouched}
  hasValue={email.length > 0}
  successMessage="Valid email"
  helpText="We'll never share your email"
>
  {#snippet children({ errors, touched })}
    <Input isRequired
      type="email"
      bind:value={email}
      {errors}
      {touched}
      onblur={() => emailTouched = true}
    />
  {/snippet}
</FormField>


COMPLETE FORM EXAMPLE
----------------------

<script lang="ts">
  import {
    Form, FormField, FormGroup, FormLabel, FormHelp, FormErrorSummary,
    Input, NumberInput, DateInput, Textarea, Select,
    Checkbox, Radio, RadioGroup, InputGroup,
    Button, Grid, Column
  } from '@keenmate/svelte-pure-admin';
  import type { FormErrorItem } from '@keenmate/svelte-pure-admin';

  // Form data
  let firstName = $state('');
  let lastName = $state('');
  let email = $state('');
  let age = $state<number | null>(null);
  let birthDate = $state('');
  let bio = $state('');
  let role = $state('');
  let newsletter = $state(false);
  let contactMethod = $state('email');
  let website = $state('');

  // Touched state
  let firstNameTouched = $state(false);
  let lastNameTouched = $state(false);
  let emailTouched = $state(false);
  let ageTouched = $state(false);
  let roleTouched = $state(false);

  let submitted = $state(false);
  let formErrors = $state<FormErrorItem[]>([]);

  // Validation functions
  function getFirstNameErrors(): string[] {
    if (!firstName.trim()) return ['First name is required'];
    if (firstName.length < 2) return ['Must be at least 2 characters'];
    return [];
  }

  function getLastNameErrors(): string[] {
    if (!lastName.trim()) return ['Last name is required'];
    return [];
  }

  function getEmailErrors(): string[] {
    if (!email) return ['Email is required'];
    if (!email.includes('@')) return ['Invalid email format'];
    return [];
  }

  function getAgeErrors(): string[] {
    if (age === null) return ['Age is required'];
    if (age < 18) return ['Must be 18 or older'];
    if (age > 150) return ['Please enter a valid age'];
    return [];
  }

  function getRoleErrors(): string[] {
    if (!role) return ['Please select a role'];
    return [];
  }

  function handleSubmit(e: Event) {
    e.preventDefault();
    submitted = true;

    // Mark all as touched
    firstNameTouched = true;
    lastNameTouched = true;
    emailTouched = true;
    ageTouched = true;
    roleTouched = true;

    // Collect all errors
    const errors: FormErrorItem[] = [];
    const fnErrors = getFirstNameErrors();
    if (fnErrors.length) errors.push({ field: 'First Name', id: 'firstName', message: fnErrors[0] });
    const lnErrors = getLastNameErrors();
    if (lnErrors.length) errors.push({ field: 'Last Name', id: 'lastName', message: lnErrors[0] });
    const emErrors = getEmailErrors();
    if (emErrors.length) errors.push({ field: 'Email', id: 'email', message: emErrors[0] });
    const ageErrors = getAgeErrors();
    if (ageErrors.length) errors.push({ field: 'Age', id: 'age', message: ageErrors[0] });
    const roleErrors = getRoleErrors();
    if (roleErrors.length) errors.push({ field: 'Role', id: 'role', message: roleErrors[0] });

    formErrors = errors;

    if (errors.length === 0) {
      console.log('Form submitted!', { firstName, lastName, email, age, birthDate, bio, role, newsletter, contactMethod, website });
    }
  }
</script>

<Form onsubmit={handleSubmit}>
  <FormErrorSummary errors={formErrors} show={submitted && formErrors.length > 0} />

  <Grid gap="md">
    <Column size="100" md="50">
      <FormField
        labelText="First Name"
        errors={getFirstNameErrors()}
        touched={firstNameTouched}
        hasValue={firstName.length > 0}
        successMessage="Looks good"
      >
        {#snippet children({ errors, touched })}
          <Input isRequired
            id="firstName"
            bind:value={firstName}
            {errors}
            {touched}
            onblur={() => firstNameTouched = true}
            placeholder="John"
          />
        {/snippet}
      </FormField>
    </Column>

    <Column size="100" md="50">
      <FormField
        labelText="Last Name"
        errors={getLastNameErrors()}
        touched={lastNameTouched}
        hasValue={lastName.length > 0}
      >
        {#snippet children({ errors, touched })}
          <Input isRequired

HORIZONTAL FORM LAYOUT
------------------------
Use horizontal prop on FormGroup or FormField for label-left layout.

<Form>
  <FormGroup horizontal isRequired>
    <FormLabel>Username</FormLabel>
    <Input bind:value={username} />
  </FormGroup>

  <FormGroup horizontal>
    <FormLabel>Email</FormLabel>
    <Input type="email" bind:value={email} />
  </FormGroup>

  <FormGroup horizontal>
    <FormLabel>Role</FormLabel>
    <Select bind:value={role}>
      <option value="user">User</option>
      <option value="admin">Admin</option>
    </Select>
  </FormGroup>
</Form>

Or with FormField:

<FormField labelText="Username" horizontal>
  {#snippet children()}
    <Input isRequired bind:value={username} />
  {/snippet}
</FormField>


INPUT SIZE COMPARISON
---------------------
All input components (Input, NumberInput, DateInput, Textarea, Select) support the same sizes.
InputGroup size should match the size of its children.

<FormGroup>
  <FormLabel>Extra Small (xs)</FormLabel>
  <Input size="xs" bind:value={v1} />
</FormGroup>

<FormGroup>
  <FormLabel>Small (sm)</FormLabel>
  <Input size="sm" bind:value={v2} />
</FormGroup>

<FormGroup>
  <FormLabel>Default</FormLabel>
  <Input bind:value={v3} />
</FormGroup>

<FormGroup>
  <FormLabel>Large (lg)</FormLabel>
  <Input size="lg" bind:value={v4} />
</FormGroup>

<FormGroup>
  <FormLabel>Extra Large (xl)</FormLabel>
  <Input size="xl" bind:value={v5} />
</FormGroup>


THEME COLORS
------------
Input, Textarea, Select, and FormHelp support themeColor prop (1-9).
This applies the pa-input--color-N / pa-textarea--color-N CSS class.

<Input bind:value={v1} themeColor={1} />
<Input bind:value={v2} themeColor={5} />
<Textarea bind:value={v3} themeColor={3} />
<Select bind:value={v4} themeColor={7}>
  <option>Option</option>
</Select>
<FormHelp themeColor={2}>Themed help text</FormHelp>


CRITICAL REMINDERS
------------------
- Use bind:value for Input, NumberInput, DateInput, Textarea, Select
- Use bind:isChecked for Checkbox, CheckboxBox
- Use bind:group for Radio
- Checkbox requires id prop (it is mandatory)
- Radio requires name and value props (they are mandatory)
- SidebarItem requires labelText prop (it is mandatory)
- errors + touched pattern: errors shown only when touched=true
- touched defaults to true on Input/NumberInput/DateInput/Textarea/Select
  (so errors show immediately unless you set touched={false} initially)
- Manual validation prop always overrides the value auto-derived from errors
- FormField children snippet receives context: { errors, touched, validation }
- FormErrorSummary uses anchor links (#id) to jump to errored fields
- InputGroup addons use class="pa-input-group__addon" directly (no component)
- All form components accept class prop for custom CSS classes
- Snippets use {#snippet name()} ... {/snippet} syntax, NOT <slot>
