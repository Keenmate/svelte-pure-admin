DATA VISUALIZATION COMPONENTS
==============================

CRITICAL: This is a Svelte 5 component library (@keenmate/svelte-pure-admin).
- All components use Svelte 5 runes ($props, $state, $derived)
- Content slots use Snippets ({@render children?.()}), NOT <slot />
- Internal BEM classes: pa-progress, pa-gauge, pa-sparkline, etc.
- CSS is provided by @keenmate/pure-admin-core (must be imported separately)
- All values (progress, bar fills) use CSS custom property --value

INSTALLATION
------------
npm install @keenmate/svelte-pure-admin

Import CSS in your layout:
<script>
  import '@keenmate/pure-admin-core/css';
</script>

-------

SHARED TYPES
------------
DataVizVariant = 'success' | 'warning' | 'danger' | 'info'

Used by: Progress, ProgressRing, Gauge, DataBar, Sparkline, BarList
These four values map to BEM modifiers: pa-progress--success, pa-gauge--danger, etc.


=====================================================================
PROGRESS BAR
=====================================================================

Linear progress bar with optional label row.

PROPS:
  value?: number              -- Progress value 0-100 (default: 0)
  labelText?: string          -- Label text (renders pa-progress-group wrapper)
  valueText?: string          -- Value text on the right side of label
  size?: 'xs' | 'sm' | 'lg'  -- Size variant
  variant?: DataVizVariant    -- Color: success, warning, danger, info
  isRounded?: boolean         -- Pill shape (default: false)
  isStriped?: boolean         -- Striped pattern (default: false)
  isAnimated?: boolean        -- Animated moving stripes (default: false)
  class?: string              -- Additional CSS classes
  children?: Snippet          -- Content rendered inside the fill bar

BASIC USAGE:

<Progress value={65} />

WITH LABEL:

<Progress value={65} labelText="Storage" valueText="65%" />

When labelText or valueText is provided, the component automatically wraps
itself in a pa-progress-group div with a pa-progress__label row above the bar.

SIZE VARIANTS:

<Progress value={40} size="xs" />
<Progress value={50} size="sm" />
<Progress value={60} />
<Progress value={80} size="lg" />

COLOR VARIANTS:

<Progress value={75} variant="success" />
<Progress value={50} variant="warning" />
<Progress value={25} variant="danger" />
<Progress value={90} variant="info" />

STYLED BARS:

<Progress value={70} isRounded />
<Progress value={70} isStriped />
<Progress value={70} isStriped isAnimated />

FULL EXAMPLE WITH LABEL AND STYLING:

<Progress
  value={82}
  labelText="Disk Usage"
  valueText="82%"
  variant="warning"
  isRounded
  isStriped
  isAnimated
/>


=====================================================================
PROGRESS GROUP
=====================================================================

Standalone label wrapper for any bar child (Progress, StackedBar, etc.).
Use this when you want a label row above a bar that does not have built-in
label support, or when composing custom bar layouts.

PROPS:
  labelText?: string    -- Label text
  valueText?: string    -- Value text (displayed on the right side)
  class?: string        -- Additional CSS classes
  children?: Snippet    -- Bar component(s) to render below the label

USAGE:

<ProgressGroup labelText="Revenue" valueText="$12,400">
  <StackedBar>
    <StackedBarSegment value={60} variant="success" />
    <StackedBarSegment value={25} variant="warning" />
    <StackedBarSegment value={15} variant="danger" />
  </StackedBar>
</ProgressGroup>

NOTE: Progress has built-in labelText/valueText props that render the same
pa-progress-group wrapper. ProgressGroup is for when you need the label row
with a different bar type (StackedBar, custom bars, etc.).


=====================================================================
PROGRESS RING
=====================================================================

Circular progress indicator using conic-gradient.

PROPS:
  value?: number            -- Progress value 0-100 (default: 0)
  valueText?: string        -- Text displayed inside the ring (e.g. "75%")
  labelText?: string        -- Label text displayed below the value
  size?: 'sm' | 'lg'       -- Size variant
  variant?: DataVizVariant  -- Color: success, warning, danger, info
  class?: string            -- Additional CSS classes
  children?: Snippet        -- Custom content inside the ring (replaces valueText/labelText)

IMPORTANT: Pass value as a plain number (0-100), NOT as a percentage string.
The SCSS calculates conic-gradient degrees internally.

BASIC USAGE:

<ProgressRing value={75} valueText="75%" />

WITH LABEL:

<ProgressRing value={75} valueText="75%" labelText="CPU" />

SIZE VARIANTS:

<ProgressRing value={60} valueText="60%" size="sm" />
<ProgressRing value={80} valueText="80%" size="lg" />

COLOR VARIANTS:

<ProgressRing value={90} valueText="90%" variant="success" />
<ProgressRing value={45} valueText="45%" variant="warning" />
<ProgressRing value={20} valueText="20%" variant="danger" />

CUSTOM CONTENT INSIDE RING:

<ProgressRing value={68}>
  <strong>68</strong>
  <small>points</small>
</ProgressRing>

When children snippet is provided, it replaces the default valueText/labelText
rendering inside the ring.


=====================================================================
GAUGE
=====================================================================

Semicircle gauge meter using conic-gradient.

PROPS:
  value?: number            -- Gauge value 0-100 (default: 0)
  valueText?: string        -- Text displayed inside the gauge
  labelText?: string        -- Label text displayed below the value
  minText?: string          -- Min label at left endpoint
  maxText?: string          -- Max label at right endpoint
  variant?: DataVizVariant  -- Color: success, warning, danger, info
  isZones?: boolean         -- Multi-zone gauge with green/yellow/red bands (default: false)
  class?: string            -- Additional CSS classes
  children?: Snippet        -- Custom content inside the gauge (replaces valueText/labelText)

IMPORTANT: isZones overrides variant. When isZones is true, the gauge shows
three color zones (green/yellow/red) regardless of the variant prop.

BASIC USAGE:

<Gauge value={72} valueText="72%" />

WITH LABELS:

<Gauge
  value={72}
  valueText="72%"
  labelText="Performance"
  minText="0"
  maxText="100"
/>

COLOR VARIANTS:

<Gauge value={85} valueText="85" variant="success" labelText="Good" />
<Gauge value={50} valueText="50" variant="warning" labelText="Medium" />
<Gauge value={20} valueText="20" variant="danger" labelText="Poor" />

MULTI-ZONE GAUGE:

<Gauge
  value={65}
  valueText="65 mph"
  labelText="Speed"
  minText="0"
  maxText="120"
  isZones
/>

The zones gauge renders green/yellow/red bands automatically based on position.

CUSTOM CONTENT:

<Gauge value={88}>
  <span style="font-size: 2rem; font-weight: bold;">A+</span>
  <span>Grade</span>
</Gauge>


=====================================================================
DATA BAR
=====================================================================

Inline horizontal bar for embedding in table cells.

PROPS:
  value?: number            -- Bar value 0-100 (default: 0)
  valueText?: string        -- Text displayed above the bar
  variant?: DataVizVariant  -- Color: success, warning, danger, info
  isNegative?: boolean      -- Red bar, right-aligned (default: false)
  class?: string            -- Additional CSS classes
  children?: Snippet        -- Additional content

BASIC USAGE:

<DataBar value={75} />

WITH VALUE TEXT:

<DataBar value={75} valueText="75%" />

COLOR VARIANTS:

<DataBar value={90} valueText="90%" variant="success" />
<DataBar value={50} valueText="50%" variant="warning" />
<DataBar value={20} valueText="20%" variant="danger" />

NEGATIVE BAR:

<DataBar value={35} valueText="-35%" isNegative />

The isNegative modifier makes the bar red and right-aligned, useful for
showing negative values, losses, or decreases in table cells.

TABLE CELL EXAMPLE:

<table class="pa-table">
  <thead>
    <tr>
      <th>Metric</th>
      <th>Value</th>
      <th>Bar</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Revenue</td>
      <td>$42,000</td>
      <td><DataBar value={84} variant="success" /></td>
    </tr>
    <tr>
      <td>Expenses</td>
      <td>$28,000</td>
      <td><DataBar value={56} variant="danger" isNegative /></td>
    </tr>
  </tbody>
</table>


=====================================================================
STACKED BAR + SEGMENTS + LEGEND
=====================================================================

Multi-segment horizontal bar chart with optional legend.

STACKED BAR PROPS:
  size?: 'sm' | 'lg'    -- Size variant
  isRounded?: boolean    -- Pill shape (default: false)
  class?: string         -- Additional CSS classes
  children?: Snippet     -- StackedBarSegment children

STACKED BAR SEGMENT PROPS:
  value?: number                                                    -- Width percentage 0-100 (default: 0)
  variant?: 'success' | 'warning' | 'danger' | 'info' | 'secondary' -- Color variant
  class?: string                                                     -- Additional CSS classes

STACKED BAR LEGEND PROPS:
  class?: string         -- Additional CSS classes
  children?: Snippet     -- StackedBarLegendItem children

STACKED BAR LEGEND ITEM PROPS:
  variant?: 'primary' | 'success' | 'warning' | 'danger' | 'info' | 'secondary' -- Swatch color (default: 'primary')
  class?: string         -- Additional CSS classes
  children?: Snippet     -- Label content

IMPORTANT: Segment values should add up to 100 (or less). Each segment's
value controls its width via the --value CSS custom property.

BASIC USAGE:

<StackedBar>
  <StackedBarSegment value={60} variant="success" />
  <StackedBarSegment value={25} variant="warning" />
  <StackedBarSegment value={15} variant="danger" />
</StackedBar>

WITH LEGEND:

<StackedBar>
  <StackedBarSegment value={60} variant="success" />
  <StackedBarSegment value={25} variant="warning" />
  <StackedBarSegment value={15} variant="danger" />
</StackedBar>
<StackedBarLegend>
  <StackedBarLegendItem variant="success">Completed (60%)</StackedBarLegendItem>
  <StackedBarLegendItem variant="warning">In Progress (25%)</StackedBarLegendItem>
  <StackedBarLegendItem variant="danger">Failed (15%)</StackedBarLegendItem>
</StackedBarLegend>

SIZE VARIANTS:

<StackedBar size="sm">
  <StackedBarSegment value={70} variant="success" />
  <StackedBarSegment value={30} variant="danger" />
</StackedBar>

<StackedBar size="lg" isRounded>
  <StackedBarSegment value={45} variant="info" />
  <StackedBarSegment value={35} variant="warning" />
  <StackedBarSegment value={20} variant="secondary" />
</StackedBar>

WITH PROGRESS GROUP LABEL:

<ProgressGroup labelText="Task Status" valueText="150 total">
  <StackedBar isRounded>
    <StackedBarSegment value={60} variant="success" />
    <StackedBarSegment value={25} variant="warning" />
    <StackedBarSegment value={15} variant="danger" />
  </StackedBar>
</ProgressGroup>

=====================================================================
HEATMAP + HEATMAP CELL + HEATMAP LEGEND
=====================================================================

Grid-based heatmap with intensity levels (GitHub contribution graph style).

HEATMAP PROPS:
  variant?: 'success' | 'danger'   -- Color palette (default: green/success)
  isCompact?: boolean               -- Smaller cells, tighter gap (default: false)
  columns?: number                  -- Grid columns (default: 53 for weekly calendar)
  class?: string                    -- Additional CSS classes
  children?: Snippet                -- HeatmapCell children

HEATMAP CELL PROPS:
  level?: 0 | 1 | 2 | 3 | 4   -- Intensity level (default: 0)
  class?: string                -- Additional CSS classes

  Level mapping:
    0 = empty/none (lightest)
    1 = low
    2 = medium
    3 = high
    4 = highest (darkest)

HEATMAP LEGEND PROPS:
  lessText?: string   -- Text before legend cells (default: "Less")
  moreText?: string   -- Text after legend cells (default: "More")
  class?: string      -- Additional CSS classes

IMPORTANT: Only two variants are supported: 'success' (green) and 'danger' (red).
The columns prop defaults to 53 (standard year in weeks). Override for custom grids.

BASIC USAGE:

<Heatmap>
  <HeatmapCell level={0} />
  <HeatmapCell level={1} />
  <HeatmapCell level={2} />
  <HeatmapCell level={3} />
  <HeatmapCell level={4} />
  <HeatmapCell level={2} />
  <HeatmapCell level={0} />
</Heatmap>
<HeatmapLegend />

CUSTOM GRID (12 COLUMNS):

<Heatmap columns={12} variant="danger">
  {#each Array(48) as _, i}
    <HeatmapCell level={Math.floor(Math.random() * 5)} />
  {/each}
</Heatmap>
<HeatmapLegend lessText="Low" moreText="High" />

COMPACT MODE:

<Heatmap isCompact columns={30}>
  {#each Array(210) as _, i}
    <HeatmapCell level={Math.floor(Math.random() * 5)} />
  {/each}
</Heatmap>

SUCCESS VARIANT (GREEN):

<Heatmap variant="success" columns={7}>
  {#each contributions as level}
    <HeatmapCell {level} />
  {/each}
</Heatmap>
<HeatmapLegend />

DANGER VARIANT (RED):

<Heatmap variant="danger" columns={7}>
  {#each errorCounts as level}
    <HeatmapCell {level} />
  {/each}
</Heatmap>
<HeatmapLegend lessText="Few errors" moreText="Many errors" />

=====================================================================
WHEN TO USE WHICH COMPONENT
=====================================================================

PROGRESS BAR
  Use for: Single metric completion (file upload, form progress, disk usage)
  Best when: You have one value 0-100 with optional label
  Example: "Storage: 82% used"

PROGRESS RING
  Use for: Compact circular KPI display (CPU, memory, scores)
  Best when: Space is limited, need visual impact, dashboard cards
  Example: "CPU 72%" in a stat card

GAUGE
  Use for: Performance meters, speed indicators, health scores
  Best when: Value has meaningful min/max range, "good/bad" zones
  Example: "Server Health: 85/100" with min=0, max=100

DATA BAR
  Use for: Inline bars inside table cells
  Best when: Comparing values across table rows
  Example: Revenue column with proportional bars

STACKED BAR
  Use for: Part-to-whole composition (status breakdown, budget allocation)
  Best when: Multiple categories that sum to 100%
  Example: "Tasks: 60% done, 25% in progress, 15% failed"

SPARKLINE
  Use for: Trend visualization in tight spaces (table cells, stat cards)
  Best when: Showing time-series data inline
  Example: Weekly revenue trend in a dashboard card

HEATMAP
  Use for: Activity patterns, contribution calendars, intensity grids
  Best when: Large dataset with categorical intensity levels
  Example: GitHub-style contribution graph

BAR LIST
  Use for: Ranked/sorted horizontal bar chart with labels
  Best when: Comparing named items with proportional bars
  Example: "Top referrers: Google 80%, Twitter 55%, GitHub 35%"

        <td>
          {#if p.growth >= 0}
            <DataBar value={p.growth} valueText="+{p.growth}%" variant="success" />
          {:else}
            <DataBar value={Math.abs(p.growth)} valueText="{p.growth}%" isNegative />
          {/if}
        </td>
        <td>
          <DataBar
            value={p.satisfaction}
            valueText="{p.satisfaction}%"
            variant={p.satisfaction >= 80 ? 'success' : p.satisfaction >= 60 ? 'warning' : 'danger'}
          />
        </td>
      </tr>
    {/each}
  </tbody>
</table>


=====================================================================
CSS CUSTOM PROPERTIES
=====================================================================

All fill-based components use the --value CSS custom property:

  Progress fill:        style="--value: {value}%"
  ProgressRing:         style="--value: {value}"       (no % suffix!)
  Gauge:                style="--value: {value}"       (no % suffix!)
  DataBar fill:         style="--value: {value}%"
  StackedBarSegment:    style="--value: {value}%"
  SparklineBar:         style="--value: {value}%"
  BarListItem bar:      style="--value: {value}%"
  Heatmap columns:      grid-template-columns: repeat({columns}, 1.2rem)
  HeatmapCell:          data-level={level}             (attribute, not CSS var)

NOTE: ProgressRing and Gauge use --value WITHOUT the % suffix because
the SCSS internally converts the value to conic-gradient degrees.
All other components use --value WITH the % suffix for direct width/height.
