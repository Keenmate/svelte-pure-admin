DATA DISPLAY COMPONENTS
=======================

CRITICAL: This is a Svelte 5 component library (@keenmate/svelte-pure-admin)
- All components use Svelte 5 runes ($props, $state, $derived)
- Content slots use Snippets ({#snippet}), NOT legacy <slot>
- All CSS classes use BEM naming: pa-[block]__[element]--[modifier]
- Import components from '@keenmate/svelte-pure-admin'

These are the "v2" data display patterns for showing read-only label-value data.
Choose the right pattern based on visual needs:
  - Field/Fields: Default for most label-value displays
  - DescTable: Ant Design style flat grid with tinted labels
  - DotLeaders: Invoice/menu style with dotted lines
  - PropCard: Stripe-style bordered card with divider rows
  - Banded: Full-width rows with tinted label column
  - AccentGrid: Dashboard grid with color-coded left borders


FIELD
-----
Single label-value pair. The fundamental building block for all data display.
Supports copyable variants with clipboard functionality.

Props:
  labelText?       string - Label text
  valueText?       string | number - Value text
  full?            boolean (false) - Full width (spans entire row in grid)
  copyMode?        'btn' | 'click' | 'hover' - Copy to clipboard mode
                     btn: always-visible copy button
                     click: click entire value to copy (shows hint on hover)
                     hover: copy button appears on hover
  copyValue?       string - Override what gets copied (defaults to valueText)
  copyValueCallback? () => string - Dynamic copy value
  copyHintText?    string - Hint text for click mode (default: i18n)
  copiedText?      string - Feedback text after copy (default: i18n)
  oncopy?          (value: string) => void - Callback after successful copy
  valueVariant?    'success' | 'warning' | 'danger' - Value color (for chips mode)
  class?           string

Snippets:
  labelSnippet?    Complex label content
  valueSnippet?    Complex value content
  children?        Alias for valueSnippet

Basic field:

<Field labelText="Name" valueText="John Doe" />
<Field labelText="Email" valueText="john@example.com" />
<Field labelText="Status" valueText="Active" valueVariant="success" />

Copyable field (always-visible button):

<Field labelText="API Key" valueText="sk-abc123..." copyMode="btn" />

Copyable field (click to copy):

<Field labelText="Order ID" valueText="ORD-2024-001" copyMode="click" />

Copyable field (button on hover):

<Field labelText="Email" valueText="john@example.com" copyMode="hover" />

Full width field (spans entire row in grid):

<Field labelText="Description" valueText="A longer description text" full />

Field with custom value snippet:

<Field labelText="Status">
  <Badge variant="success">Active</Badge>
</Field>

Field with custom label snippet:

<Field valueText="john@example.com">
  {#snippet labelSnippet()}
    <strong>Email</strong> <Badge variant="info" size="xs">Primary</Badge>
  {/snippet}
</Field>

Field with dynamic copy value:

<Field
  labelText="Token"
  valueText="****-****-1234"
  copyMode="btn"
  copyValueCallback={() => fullToken}
/>


FIELDS
------
Container for multiple Field components with extensive layout modifiers.

Props:
  cols?              2 | 3 | 4 - Grid columns
  isHorizontal?      boolean (false) - Label left, value right (side-by-side)
  isTable?           boolean (false) - Consistent label widths (key-value table)
  isBordered?        boolean (false) - Bottom border separator between fields
  isStriped?         boolean (false) - Alternating background rows
  isCompact?         boolean (false) - Tighter spacing
  isRelaxed?         boolean (false) - Larger gaps
  isInline?          boolean (false) - Fields flow on one line
  isRow?             boolean (false) - Equal-width auto columns
  isLinear?          boolean (false) - Ultra-clean side-by-side, weight+color only
  isChips?           boolean (false) - Notion-style inline pills
  isFilled?          boolean (false) - Subtle background panel
  color?             1-9 - Theme color for left border
  hasBorder?         boolean (true) - Show left border (false to remove)
  hasContainerQuery? boolean (false) - Wrap for CSS container query responsiveness
  class?             string
  children?          Snippet

Default vertical layout (2 columns):

<Fields cols={2}>
  <Field labelText="First Name" valueText="John" />
  <Field labelText="Last Name" valueText="Doe" />
  <Field labelText="Email" valueText="john@example.com" />
  <Field labelText="Phone" valueText="+1 555-0123" />

Horizontal layout (label left, value right):

DESCTABLE / DESCTABLEITEM
--------------------------
Ant Design style flat grid with label/value cells. Label cells get a tinted
background for visual grouping. Best for structured detail pages.

DescTable Props:
  cols?              2 | 3 (default: 3) - Number of label-value columns
  isFixed?           boolean (false) - Fixed-width label columns (default 14rem)
  labelWidth?        string - Custom label width CSS (e.g. '20rem'), requires isFixed
  isMiddle?          boolean (false) - Vertically center labels and values
  isLabelEnd?        boolean (false) - Right-align labels
  isLabelCenter?     boolean (false) - Center-align labels
  isTruncate?        boolean (false) - Single-line ellipsis on labels and values
  hasContainerQuery? boolean (false) - Wrap for CSS container query responsiveness
  class?             string
  children?          Snippet

DescTableItem Props:
  labelText          string (required) - Label text
  valueText?         string | number - Value text
  full?              boolean (false) - Value spans remaining columns in row
  copyMode?          'btn' | 'click' | 'hover'
  copyValue?         string - Override copy value
  oncopy?            (value: string) => void
  class?             string
  children?          Snippet - Complex value content

Three-column descriptions table (default):

WHEN TO USE WHICH PATTERN
--------------------------

Field/Fields (default choice):
  Use when: Most label-value displays, detail pages, forms, settings
  Best for: Flexible layouts, 2-4 column grids, horizontal/vertical orientation
  Unique: isLinear, isChips, color variants, container query support

DescTable:
  Use when: Structured detail pages with many properties
  Best for: Ant Design style, tinted label cells, 2-3 column grids
  Unique: Fixed-width labels, tinted backgrounds, grid-based layout

DotLeaders:
  Use when: Invoices, pricing pages, restaurant menus, receipt summaries
  Best for: Label ... value with dotted connecting line
  Unique: isTotal for bold summary rows, dotted leader lines

PropCard:
  Use when: Settings panels, payment details, subscription info
  Best for: Stripe-style bordered card with divider rows
  Unique: headerText for card title, isBold for emphasis

Banded:
  Use when: System info, configuration details, server status
  Best for: Full-width rows with tinted label column
  Unique: Width variants (narrow/wide), label alignment options

AccentGrid:
  Use when: Dashboards, KPI panels, status overviews
  Best for: Color-coded status indicators, responsive grid
  Unique: variant for border color (success/warning/danger/info)

COPY MODE COMPARISON
---------------------
All data display components (Field, DescTableItem, PropCardRow, BandedRow,
AccentGridItem) support the same three copy modes:

  copyMode="btn"     Always-visible copy button next to the value
                     Best for: Values that are frequently copied (IDs, tokens)

  copyMode="click"   Click the entire value text to copy, hint appears on hover
                     Best for: Clean UI, values occasionally copied

  copyMode="hover"   Copy button appears only on hover
                     Best for: Dense layouts, copy available but not prominent

- Use Svelte 5 runes: $props(), $state(), $derived()
- Content uses Snippets ({#snippet name()}...{/snippet}), NOT <slot>
- Event handlers are lowercase: onclick, oncopy (NOT onClick)
- Boolean props use is* prefix: isHorizontal, isBordered, isTotal, isBold
- Fields is the container, Field is the individual item
- DescTable is the container, DescTableItem is the individual item
- DotLeaders is the container, DotLeadersItem is the individual item
- PropCard is the container, PropCardRow is the individual item
- Banded is the container, BandedRow is the individual item
- AccentGrid is the container, AccentGridItem is the individual item
- Field "full" prop spans the entire row in a grid layout
- DescTableItem "full" prop spans remaining columns in the row
- Fields "color" prop (1-9) adds themed left border
- AccentGridItem "variant" controls the left border color
- Field "valueVariant" colors the value text (for chips mode)
- DotLeadersItem "isTotal" makes the row bold with a top border
